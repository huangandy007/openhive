# opencode 学习记录

本目录用于记录对 [opencode](https://github.com/anomalyco/opencode)（本项目 openhive 的上游）的学习笔记。

## 说明

- 这些笔记**只提交到 `learning` 分支**，与 `main` 分支上的定制改造分离。
- 笔记只放本目录，**不改动 `packages/` 下的代码**。
- 上游 `dev` 没有本目录，因此 merge 上游/`main` 时零冲突。

## 目录组织规则

- 按「学习规划的六层」分文件夹：`NN-层名/`（`NN` 为两位序号，保证排序）。
- 层内文档用 `NN-主题.md` 排序。
- 内容多的主题在同一层内**拆成多篇**，不写超长单篇。
