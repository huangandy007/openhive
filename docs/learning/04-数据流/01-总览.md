## 一、读这一层之前，先记住一个「坑」

opencode 现在**同时跑着两套 session 实现**，而且 `opencode serve` 一个进程里两套 API 都暴露着：

| | 链 A（旧 V2 API） | 链 B（新 instance API） |
|---|---|---|
| 请求路径 | `/api/session/:sessionID/prompt` | `/session/:sessionID/message` |
| 会话层类 | `SessionV2`（`packages/core/src/session.ts`） | `SessionPrompt`（`packages/opencode/src/session/prompt.ts`） |
| 执行模型 | **持久化准入 → 异步 wake → drain** | **同步跑完 agent loop 返回消息** |
| 定位 | CONTEXT.md 描述的「新 V2 Session Runtime」（事件溯源、context epoch） | legacy 聊天主循环（迁移前的旧实现） |

**命名陷阱（务必警惕）**：`SessionV2` 名字里带「V2」，是**新**的（迁移目标）；`SessionPrompt` 不带「V2」，反而是**旧**的。但看路径，`/api` 显得旧、`/session` 显得新——**别被路径迷惑**。判断新旧看**代码位置和机制**：`SessionV2` 在 `packages/core` 且有事件溯源（`event` 表）、context epoch（`session_context_epoch` 表），才是新架构。

> 这就是 `01-学习规划` 里说的「V2 与 legacy 并存」的具体体现。读代码时先问：这段属于哪一套？

## 二、两条完整调用链（一图流）

### 链 A：持久化 + 异步执行（新 V2）

```
POST /api/session/:id/prompt
  → NodeHttpServer（server.ts:214）
  → HttpRouter → serverRoutes
  → SessionHandler（packages/server/src/handlers/session.ts:139）
  → SessionV2.prompt（core/src/session.ts:360）
      ├─ SessionInput.admit(...)         // ① 持久化：写 session_input 行
      └─ execution.wake(sessionID)       // ② 调度：唤醒执行
  → SessionRunCoordinator.wake → start → drain（run-coordinator.ts）
  → SessionRunner.run（runner/llm.ts:383）→ runTurn → llm.stream(...)
```

### 链 B：直接同步跑 loop（legacy）

```
POST /session/:id/message
  → HttpRouter → instanceRoutes
  → sessionHandlers（opencode/.../handlers/session.ts:295）
  → SessionPrompt.prompt（opencode/src/session/prompt.ts:1052）
      ├─ createUserMessage(...)          // 写 user message + parts
      └─ loop({sessionID})               // 进入 agent 主循环
          → runLoop → processor.process → llm.stream(...)
```

**共同点**：两条链最终都汇聚到「调 `llm.stream` 请求模型」这一步。区别在于**「输入如何被接住、如何被调度」**——链 A 是「先持久化、再异步唤醒」，链 B 是「当场直接跑」。

## 三、为什么会有两套？

这是 opencode 团队正在做的一次大重构（V2 Session Core）的中途状态：

- **旧实现**（`SessionPrompt`）：消息直接写库、同步跑循环，简单但难以支持「暂停/恢复/跨进程/事件回放」等能力。
- **新实现**（`SessionV2`）：引入**事件溯源**（`event` 表）和**持久化输入队列**（`session_input` 表），把「准入」和「执行」解耦，为分布式、可恢复的会话运行时打基础。

两者现在都还连着，等旧实现逐步被替换掉。**学习时两条都要看懂**，但重点放在新 V2（它是未来，也是 `03-核心概念` 里那套词汇的真正对应物）。
