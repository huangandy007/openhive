# 项目文件树批量取数 · 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把「前端逐目录请求（约 100 趟）」换成「服务端一次遍历、一次返回」，清单内容与顺序逐字不变。

**Architecture:** 服务端新增 `GET /openhive/project/tree`，在一次请求内用 `FileSystem.Service.list` 递归走完整棵树（复用 `ignore` 规则与隐藏根判据），返回 `{ paths, truncated }`；前端 `listProjectFiles` 改为读它，删除 `walk` / 并发闸门 / `isHiddenRoot`。

**Tech Stack:** Effect 4 · `HttpRouter` · Bun test · SolidJS（前端只改取数层）

**Spec:** `docs/superpowers/specs/2026-10-28-项目文件树批量取数-design.md`

## Global Constraints

- 上限 **50000** 条路径；达到即停止遍历，置 `truncated: true`；**界面必须如实提示**，不得静默截断。
- `paths` 与今天前端 `walk` 的产出**逐字、逐序相同**（规则见 spec §3）。
- 隐藏根判据（首段 `.git` / `.opencode`，不分大小写，只看第一段）**只留服务端一份**。
- **不改上游文件**：`file.ts`、`api.ts` 一个字不动；新增的都在 `server/openhive/` 下。
- 任何一层读不到 ⇒ 整份 `undefined`，**不交半棵树**（截断是唯一例外，且必须带 `truncated`）。
- 门禁：`packages/opencode` 与 `packages/app` 各自 `bun run typecheck` ＋ 受影响测试；仓库根 `bunx oxlint` 0 warning。
- `bun test` 一律带 `timeout 300`；根目录禁止跑 `bun test`。

```ts
export * as OpenhiveProjectTreeScan from "./project-tree-scan"

/**
 * 项目文件树的**服务端遍历**（2026-10-28）。
 *
 * 逐字复刻前端 `packages/app/src/project/openhive-files.ts` 里 `walk` 的产出口径：
 * **文件就地收下，目录钻进去、回来再按原位置补，空目录补自己**。顺序一漂，树就画错
 * （文件跑到别的目录底下、空目录挤到最前面）——所以那份前端的对应用例**整组迁到了这里**。
 *
 * ## 为什么前半段是纯函数、读目录靠注入
 *
 * 「顺序」这件事与文件系统无关，能用一个按路径分派的替身完整钉住。接线层（`project-tree.ts`）
 * 只负责把 `FileSystem.list` 与 `ignore` 规则塞进来——那一层才是真 IO，它由真栈验收兜底。
 *
 * ## ignored 在这里过滤，不在接线层
 *
 * 前端的口径是「ignored 的文件跳过；ignored 的目录**不进去走**」。两半都在这一层做，
 * 才有一条用例能同时钉住它们（接线层过滤文件、扫描层不跳目录的话，仍会白走一趟）。
 */

export type 条目 = { path: string; type: "file" | "directory"; ignored: boolean }

/** 读一层目录。`undefined` ＝ 这一层取不到（整份判为取不到）。 */
export type 读目录 = (dir: string) => Promise<readonly 条目[] | undefined>

export type 扫描结果 = { paths: string[]; truncated: boolean }

/** 上限：达到即停，置 `truncated`。数值的依据见 design §4。 */
export const 默认上限 = 50000

/**
 * 整条路径的**第一段**是 `.git` / `.opencode`（不分大小写）⇒ 不画、也不往下走。
 *
 * 「第一段」不是「任何一段」：`资料\.git\` 是项目内容（解压进来的一份仓库），照常显示。
 * 与 `packages/opencode/src/server/openhive/file.ts` 的 `inGit` 逐字同形——两处边界漂了
 * 就是「看得见却动不了」或「动得了却看不见」。
 *
 * ⚠️ 不是安全边界：拦改动的是 `file.ts` 那八个守卫；`.opencode` 服务端没有任何守卫，
 * 这里只是不画、不遍历。
 */
function 隐藏根(path: string): boolean {
  const 首段 = (path.split(/[\\/]/)[0] ?? "").toLowerCase()
  return 首段 === ".git" || 首段 === ".opencode"
}

export async function 扫树(读: 读目录, 上限: number = 默认上限): Promise<扫描结果 | undefined> {
  const paths: string[] = []
  let truncated = false

  /** `undefined` ＝ 这一支走不成；`true`/`false` ＝ 这一支下面有没有**文件**。 */
  async function walk(dir: string): Promise<boolean | undefined> {
    if (truncated) return false
    const body = await 读(dir)
    if (body === undefined) return undefined

    let 有文件 = false
    for (const entry of body) {
      if (entry.ignored || 隐藏根(entry.path)) continue
      if (entry.type !== "directory") {
        if (paths.length >= 上限) {
          truncated = true
          return false
        }
        paths.push(entry.path)
        有文件 = true
        continue
      }
      const 下面有文件 = await walk(entry.path)
      if (下面有文件 === undefined) return undefined
      if (!下面有文件) {
        if (paths.length >= 上限) {
          truncated = true
          return false
        }
        paths.push(entry.path)
      }
      有文件 = 有文件 || 下面有文件
    }
    return 有文件
  }

  const 成 = await walk("")
  if (成 === undefined) return undefined
  return { paths, truncated }
}
```

### ⚠️ 目录从哪来（读码结论，决定下面整段写法）

`handlers/file.ts` 用 `InstanceState.context` 取当前目录，但那是 `HttpApiBuilder.group` 里的特权——
**`HttpRouter.use` 这一层拿不到它**（`packages/core/src/database/router.ts` 的 `hook` 注释实测原话：
「请求 fiber 的 context 里**没有 app 层服务**」）。本端点因此走**另一条**：`projectLocationLayer`
在处理下游之前，已经把 `?directory=` 与 `x-opencode-directory` **双双击成项目目录**
（`middleware/project-location.ts` 的 `rewriteRequest`）。所以：

- 请求期只做一件事：从 `request.url` 取 `?directory=`（**不自己拼路径**，也不读项目头——那头已被
  中间件摘掉）；
- 取不到 ⇒ **400**（说明这一枪没经过中间件，或者调用方没带项目通道——两种情况都不该由本端点猜）；
- 服务（`LocationServiceMap`）在**层构造期**取一次，请求期只用闭包。

```ts
export * as OpenhiveProjectTree from "./project-tree"

import { FileSystem } from "@opencode-ai/core/filesystem"
import { FSUtil } from "@opencode-ai/core/fs-util"
import { Location } from "@opencode-ai/core/location"
import { LocationServiceMap } from "@opencode-ai/core/location-services"
import { AbsolutePath, RelativePath } from "@opencode-ai/core/schema"
import { Effect } from "effect"
import ignore from "ignore"
import path from "node:path"
import { HttpRouter, HttpServerResponse } from "effect/unstable/http"
import { 扫树, type 条目, type 读目录 } from "./project-tree-scan"

const PATH = "/openhive/project/tree"

export const routes = HttpRouter.use((router) =>
  Effect.gen(function* () {
    // 构造期取、请求期用（`packages/core/src/database/router.ts` 的 `hook` 注释实测：请求 fiber 里没有 app 层服务）。
    const locations = yield* LocationServiceMap.Service

    yield* router.add("GET", PATH, (request) =>
      Effect.gen(function* () {
        // 目录由 `projectLocationLayer` 的 `rewriteRequest` 写好——本层**不自己拼**、也不读项目头（已被摘掉）。
        const 目录 = new URL(request.url, "http://localhost").searchParams.get("directory")
        if (!目录) return HttpServerResponse.jsonUnsafe({ error: "没有项目上下文" }, { status: 400 })

        const 层 = locations.get(Location.Ref.make({ directory: AbsolutePath.make(目录) }))

        // ignore 规则**一趟请求读一次**（`/file` 是每请求读一次，本端点只看一次，这是顺带的改进）。
        const 规则 = yield* Effect.gen(function* () {
          const raw = yield* FSUtil.Service
          const location = yield* Location.Service
          const ignored = ignore()
          for (const 名 of [".gitignore", ".ignore"]) {
            const text = yield* raw
              .readFileString(path.join(location.project.directory, 名))
              .pipe(Effect.catch(() => Effect.succeed("")))
            if (text) ignored.add(text)
          }
          return ignored
        }).pipe(Effect.provide(层))

        const 读: 读目录 = (dir) =>
          Effect.runPromise(
            Effect.gen(function* () {
              const fs = yield* FileSystem.Service
              const location = yield* Location.Service
              // ⚠️ `item.path` 是**相对 location.directory** 的（`filesystem.ts` 的 `list`：
              // `path.relative(target.directory, absolute)`），不是相对 `dir`——所以不用再拼 dir。
              return (yield* fs.list({ path: RelativePath.make(dir) })).map(
                (item): 条目 => ({
                  path: item.path,
                  type: item.type,
                  ignored: 规则.ignores(
                    path.relative(location.project.directory, path.resolve(location.directory, item.path)) +
                      (item.type === "directory" ? "/" : ""),
                  ),
                }),
              )
            }).pipe(
              Effect.provide(层),
              Effect.catch(() => Effect.succeed<readonly 条目[] | undefined>(undefined)),
            ),
          )

        const 结果 = await 扫树(读)
        if (结果 === undefined) return HttpServerResponse.jsonUnsafe({ error: "读取文件树失败" }, { status: 500 })
        return HttpServerResponse.jsonUnsafe(结果)
      }),
    )
  }),
)
```

```ts
/** 批量取树的出口（2026-10-28）。**测试里写字面量、不 import 本常量**（`#003-05`）。 */
export const TREE_PATH = "/openhive/project/tree"

export type ProjectTree = { paths: readonly string[]; truncated: boolean }

export async function listProjectTree(
  projectId: string,
  send: ProjectFilesFetch = defaultSend,
): Promise<ProjectTree | undefined> {
  const response = await trySend(send, TREE_PATH, {
    credentials: "same-origin",
    headers: { [PROJECT_HEADER]: projectId },
  })
  if (!response?.ok) return undefined

  const body = await readJson(response)
  if (!isRecord(body)) return undefined
  const paths = body.paths
  if (!Array.isArray(paths) || paths.some((item) => typeof item !== "string")) return undefined
  return { paths, truncated: body.truncated === true }
}

export async function listProjectFiles(
  projectId: string,
  send: ProjectFilesFetch = defaultSend,
): Promise<readonly string[] | undefined> {
  return (await listProjectTree(projectId, send))?.paths
}
```
