# 卡片模板编辑器（P4 第二刀）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让民警在界面里新建 / 修改 / 预览 / 转正 / 停用 / 恢复本项目的卡片模板，不必改代码或 SQL。

**Architecture:** 内核补两口（词表 `GET card-template/vocab`、恢复 `POST card-template/restore`），前端新增独立视图 `case://<projectId>/templates/all`（列表 + 抽屉编辑器 + 预览结果区），入口挂在材料抽取视图顶部工具条。词表（槽 / 事件类型 / 字段 / 角色 / 实体类型）**全部由内核派生**，前端不复制任何「哪个槽收哪类字段」的规则；服务端中文错误原样展示。

**Tech Stack:** Effect（内核 HTTP）、Drizzle/SQL、Bun test、SolidJS 1.9 + Kobalte、`@opencode-ai/ui/v2` 的 ButtonV2 / TextInputV2 / SelectV2 / CheckboxV2。

**Spec:** `docs/superpowers/specs/2026-11-09-事实卡片抽象/2026-11-14-P4-卡片模板-编辑器-design.md`（下称「设计」）。本计划与设计的两处计划期裁定见文末「裁定与偏差」。

```ts
export interface 模板词表 {
  readonly 槽们: readonly 槽[]
  readonly 事件类型们: readonly { readonly 值: 事件类型; readonly 可选: boolean; readonly 原因?: string }[]
  readonly 字段们: readonly { readonly 值: 识别字段; readonly 显示名: string; readonly 种类: 字段种类 }[]
  readonly 槽可选字段们: { readonly [K in 槽]: readonly 识别字段[] }
  readonly 其他不可选种类: readonly 字段种类[]
  readonly 角色们: readonly { readonly 值: 角色; readonly 地点类: boolean }[]
  readonly 默认角色: { readonly 谁: 角色; readonly 和谁: 角色; readonly 何地: 角色 }
  readonly 实体类型们: readonly string[]
  readonly 必填恒含: 槽
}

/**
 * 编辑器词表（设计 §3）：**零新判据**，全部从现有常量派生。
 *
 * 前端拿数组直接渲染，不再自己判「哪个槽收哪类字段」——同一条规则两处各写一遍，
 * 下一次加字段时必有一边忘改（`#002-06`）。改词表 = 改本文件的源常量，前端刷新即换代。
 */
export function 模板词表(): 模板词表 {
  const 字段们 = Object.keys(字段目录) as 识别字段[]
  const 槽可选 = Object.fromEntries(
    九格们.map((槽名) => [槽名, 字段们.filter((字段) => 槽收字段(槽名, 字段))]),
  ) as Record<槽, 识别字段[]>
  return {
    槽们: 九格们,
    事件类型们: 事件类型们.map((值) =>
      值 === 资金交易 || 值 === "住宿"
        ? { 值, 可选: false, 原因: 不能建用户模板原因 }
        : { 值, 可选: true },
    ),
    字段们: 字段们.map((值) => ({ 值, 显示名: 字段显示名[值], 种类: 字段目录[值].种类 })),
    槽可选字段们: 槽可选,
    其他不可选种类: 其他拒收种类,
    角色们: 角色们.map((值) => ({ 值, 地点类: 地点角色集.has(值) })),
    默认角色,
    实体类型们: [...实体类型们],
    必填恒含: "谁",
  }
}
```

> `事件类型们` 需在 `case-card-template.ts` 的 import 里补：`import { 资金交易, 事件类型们, 是事件类型, type 事件类型 } from "./case-event-types"`。

```ts
/**
 * 恢复：把 `disabled_at` 置回 null（设计 §4）。
 *
 * 先用**一条带条件的 UPDATE**，0 行后再回读区分三种成因（已启用 / 不存在 / 并发改回）：
 * - 回读放在 UPDATE 之后而不是之前：判定依据是「这次 UPDATE 真的改到了没有」，
 *   不是「读的时候看起来是什么」（先读再写会把这个窗口里的状态当成结论）。
 * - 同类型已有启用中的用户模板 ⇒ 唯一索引 23505，翻成 conflict 的人话；
 *   这个分支**只有**在真去恢复时才会触发，所以它是恢复语义的真闸。
 * - 恢复不改 `verified_at` / `version`：验证状态管的是「这一版的定义」，停用/恢复不动定义。
 */
export async function 恢复模板(db: Queryable, input: { projectId: string; id: string }): Promise<void> {
  要求用户模板(input.id, "恢复")
  let 行们: Record<string, unknown>[]
  try {
    行们 = rowsOf(
      await db.execute(sql`
        update auth.case_card_template
           set disabled_at = null
         where project_id = ${input.projectId} and id = ${input.id} and disabled_at is not null
         returning id
      `),
    )
  } catch (错误: unknown) {
    if (pgErrorCode(错误) === "23505") {
      throw new 模板错误("conflict", "同类型下已有启用中的用户模板；请先停用旧模板再恢复")
    }
    throw 错误
  }
  if (行们.length > 0) return
  const 现有 = await 读模板行(db, input.projectId, input.id)
  if (现有 === undefined) throw new 模板错误("not_found", "没有这个模板")
  if (现有.disabled_at === null) return // 已启用：幂等
  // UPDATE 0 行但回读仍是停用 ⇒ 两次读之间被别的请求改回了停用；让用户刷新重来。
  throw new 模板错误("state_changed", "模板状态在恢复期间被改动，请刷新后重试")
}
```

```ts
function handleCardTemplateRestore(request: HttpServerRequest.HttpServerRequest, deps: Deps) {
```

- [ ] **Step 3: 抽 `请求带错误体` 并让 `请求` 复用（改 `entity-api.ts`）**

把现有 `请求<T>` 整个函数替换为下面两段（**逻辑一字不改**，只是把「错误体」这个额外产物交出去）：

```ts
/**
 * 同 `请求<T>`，但错误分支额外带原始错误体（`错误体`）。
 *
 * 只有一个消费方：模板转正。它的 400 `preview_failed` 把 0 卡原因表放在错误体里
 * （内核 `case-ui-routes.ts` 的 verify handler）——丢了这个字段，民警只看到「没有卡片」，
 * 看不到卡在哪一列。**超时 / 网络 / 非 JSON 的分支仍只有这一份实现**（`#002-06`）。
 */
export async function 请求带错误体<T>(
  send: CaseFetch,
  url: string,
  init?: RequestInit,
): Promise<(结果<T> & { readonly 错误体?: unknown })> {
  try {
    const response = await send(url, init)
    if (!response.ok) {
      const 体 = (await response.json().catch(() => undefined)) as { error?: string; code?: string } | undefined
      return { kind: "error", message: 体?.error ?? `服务端回了 ${response.status}`, code: 体?.code, 错误体: 体 }
    }
    try {
      return { kind: "ok", value: (await response.json()) as T }
    } catch {
      return { kind: "error", message: `服务端回了非 JSON（${response.status}）` }
    }
  } catch (错误) {
    if (错误 instanceof Error && 错误.name === "AbortError")
      return { kind: "error", message: 超时提示, code: "timeout" }
    return { kind: "error", message: 错误 instanceof Error ? 错误.message : String(错误) }
  }
}

/** 同源 JSON 取数：非 2xx 收成 `{kind:"error"}`，**从不抛**（视图只管画，不管异常）。 */
export async function 请求<T>(send: CaseFetch, url: string, init?: RequestInit): Promise<结果<T>> {
  const 回 = await 请求带错误体<T>(send, url, init)
  // 收窄回原本的形状：`错误体` 不外溢，既有调用方与 `toEqual` 精确断言一个字都不变。
  if (回.kind === "ok") return { kind: "ok", value: 回.value }
  return 回.code === undefined
    ? { kind: "error", message: 回.message }
    : { kind: "error", message: 回.message, code: 回.code }
}
```

```ts
 * 词表缓存：**只在成功时写入**。失败（网络 / 内核没升级）下次重试；页面刷新即换代。
 * 词表是代码常量，进程内不会变——设计 §3 的「刷新即换代」就是这一行。
 */

/** 测试用：清掉模块级缓存（生产代码不调用）。 */
export function 复位词表缓存(): void {
  词表缓存 = undefined
}

export function createCaseTemplateApi(send: CaseFetch = 默认发送): CaseTemplateApi {
  return {
    list: async (projectId, 含停用) => {
      const 参数 = new URLSearchParams({ projectId })
      if (含停用 === true) 参数.set("含停用", "true")
      const 回 = await 请求<{ list: 模板行[] }>(send, `${PREFIX}/card-templates?${参数.toString()}`)
      return 回.kind === "error" ? 回 : { kind: "ok", value: 回.value.list }
    },

    vocab: async () => {
      if (词表缓存 !== undefined) return { kind: "ok", value: 词表缓存 }
      const 回 = await 请求<模板词表>(send, `${PREFIX}/card-template/vocab`)
      if (回.kind === "error") return 回
      词表缓存 = 回.value
      return { kind: "ok", value: 回.value }
    },

    create: (input) =>
      请求<模板行>(send, `${PREFIX}/card-template/create`, 体({ method: "POST", body: JSON.stringify(input) })),

    update: (input) =>
      请求<模板行>(send, `${PREFIX}/card-template/update`, 体({ method: "POST", body: JSON.stringify(input) })),

    disable: (input) =>
      请求<{ ok: true }>(send, `${PREFIX}/card-template/disable`, 体({ method: "POST", body: JSON.stringify(input) })),

    restore: (input) =>
      请求<{ ok: true }>(send, `${PREFIX}/card-template/restore`, 体({ method: "POST", body: JSON.stringify(input) })),

    preview: (input) =>
      请求<预览输出>(send, `${PREFIX}/card-template/preview`, 体({ method: "POST", body: JSON.stringify(input) })),

    verify: async (input) => {
      const 回 = await 请求带错误体<转正输出>(
        send,
        `${PREFIX}/card-template/verify`,
        体({ method: "POST", body: JSON.stringify(input) }),
      )
      if (回.kind === "ok") return { kind: "ok", value: 回.value }
      const 跳过 = 读跳过(回.错误体)
      return {
        kind: "error",
        message: 回.message,
        ...(回.code === undefined ? {} : { code: 回.code }),
        ...(跳过 === undefined ? {} : { 跳过 }),
      }
    },
  }
}

/** 错误体里的 `跳过: {原因: 数}`：形状不对就不带（宁可不显示，也不猜）。 */
function 读跳过(体: unknown): Record<string, number> | undefined {
  if (typeof 体 !== "object" || 体 === null) return undefined
  const 原 = (体 as { 跳过?: unknown }).跳过
  if (typeof 原 !== "object" || 原 === null || Array.isArray(原)) return undefined
  const 出: Record<string, number> = {}
  for (const [键, 值] of Object.entries(原)) {
    if (typeof 值 !== "number" || !Number.isInteger(值) || 值 < 0) return undefined
    出[键] = 值
  }
  return 出
}
```

```ts
import type { 模板槽名, 模板定义输入, 模板行, 模板词表, 槽填法 } from "../../project/case-template-api"
import { 模板槽名们 } from "../../project/case-template-api"

/**
 * 编辑器的表单模型（纯函数，不碰 DOM / 下拉）。
 *
 * 为什么单独一个文件：Kobalte 下拉在 happy-dom 里要点开、按 `pointerup` 才选中（`#006-37`），
 * 把「选了什么 → 变成什么定义」压进组件测试会把用例写成驱动第三方组件。表单形状在这里可单测，
 * 组件只管画与转发。
 */
export type 槽表 = { [K in 模板槽名]: readonly 槽填法[] }

export interface 表单 {
  readonly name: string
  readonly eventType: string
  readonly 槽表: 槽表
  readonly required: readonly 模板槽名[]
}

/**
 * 单值槽：与内核 `单值槽` 同一集合（`case-card-template.ts`）。
 * **「何地」不在其中**——内核允许多条，见设计 §5.3 的计划期更正 R1。
 */
const 单值槽们: readonly 模板槽名[] = ["谁", "何时", "何时止", "多少钱"]

/** 全空槽表：TS 会检查七个键一个不缺（少写一个键 = 编译红，不是运行时 undefined）。 */
function 空槽表(): 槽表 {
  return { 谁: [], 和谁: [], 何时: [], 何时止: [], 何地: [], 多少钱: [], 其他: [] }
}

export function 新表单(词表: 模板词表): 表单 {
  const 角色 = 词表.默认角色.谁
  return {
    name: "",
    eventType: "",
    槽表: { ...空槽表(), 谁: [{ 字段: "", 角色 }] },
    required: [词表.必填恒含],
  }
}

/** 库里单值槽是对象、多值槽是数组；两种都归一成行数组。 */
function 读槽(值: 模板行["slots"][模板槽名]): readonly 槽填法[] {
  if (值 === undefined || 值 === null) return []
  const 项们 = Array.isArray(值) ? 值 : [值]
  return 项们.map((项) => {
    const 行: { 字段: string; 角色?: string; 实体类型?: string } = { 字段: 项.字段 }
    if (项.角色 !== undefined && 项.角色 !== "") 行.角色 = 项.角色
    if (项.实体类型 !== undefined && 项.实体类型 !== "") 行.实体类型 = 项.实体类型
    return 行
  })
}

export function 从行(行: 模板行, 词表: 模板词表): 表单 {
  const 槽表 = 空槽表()
  for (const 槽名 of 模板槽名们) 槽表[槽名] = 读槽(行.slots[槽名])
  if (槽表.谁.length === 0) 槽表.谁 = [{ 字段: "", 角色: 词表.默认角色.谁 }]
  return { name: 行.name, eventType: 行.event_type, 槽表, required: 行.required }
}

/** 表单 → HTTP 定义体。空行 / 空角色 / 空实体类型一律不写（服务端讨厌空串胜过多余键）。 */
export function 成定义(表单值: 表单): 模板定义输入 {
  const slots: Record<string, unknown> = {}
  for (const 槽名 of 模板槽名们) {
    const 条们 = 表单值.槽表[槽名]
      .filter((填) => 填.字段 !== "")
      .map((填) => {
        const 项: { 字段: string; 角色?: string; 实体类型?: string } = { 字段: 填.字段 }
        if (填.角色 !== undefined && 填.角色 !== "") 项.角色 = 填.角色
        if (填.实体类型 !== undefined && 填.实体类型 !== "") 项.实体类型 = 填.实体类型
        return 项
      })
    if (条们.length === 0) continue
    slots[槽名] = 单值槽们.includes(槽名) ? 条们[0] : 条们
  }
  return {
    name: 表单值.name.trim(),
    eventType: 表单值.eventType,
    slots: slots as 模板定义输入["slots"],
    required: 表单值.required,
  }
}

/**
 * 即时校验（设计 §5.4）：只判**前端能判**的（必填、空选、表外字段）。
 * 槽位种类、字段重复、条数上限、事件类型不可选这些服务端判据**不在这里复制**——
 * 保存时原样展示服务端中文串（`#002-06`）。
 */
export function 校验表单(表单值: 表单, 词表: 模板词表): string[] {
  const 错: string[] = []
  if (表单值.name.trim() === "") 错.push("请填写模板名称")
  if (表单值.eventType === "") 错.push("请选择事件类型")
  if ((表单值.槽表.谁[0]?.字段 ?? "") === "") 错.push("「谁」必须选一个字段")
  for (const 槽名 of 模板槽名们) {
    for (const 填 of 表单值.槽表[槽名]) {
      if (填.字段 === "") continue
      if (!词表.槽可选字段们[槽名].includes(填.字段))
        错.push(`「${槽名}」的字段 ${填.字段} 不在该槽可选集里`)
    }
  }
  for (const 槽名 of 表单值.required) {
    if (表单值.槽表[槽名].every((填) => 填.字段 === "")) 错.push(`「${槽名}」勾了必填但还没选字段`)
  }
  return 错
}

/** 预览是否已过期：预览时的定义快照与当前定义不同即过期（设计 §6.1）。 */
export function 预览已过期(预览时: string | undefined, 当前: string): boolean {
  return 预览时 !== undefined && 预览时 !== 当前
}
```

```tsx
/** 一个槽的控件：单行（谁/何时/何时止/多少钱）或多行（和谁/何地/其他）。 */
function 槽选区(props: {
  readonly 槽名: 模板槽名
  readonly 词表: 模板词表
  readonly 条们: readonly 槽填法[]
  readonly 只读: boolean
  readonly 多行: boolean

    if (值 === 无选项) return "无"
    return props.词表.字段们.find((项) => 项.值 === 值)?.显示名 ?? 值

                <SelectV2

                  appearance="base"

                  placeholder="角色"
                  label={(值) =>
                    值 === 默认选项 ? `默认（${默认角色(props.词表, props.槽名) ?? "无"}）` : 值
                  }
                  disabled={props.只读}
                  onSelect={(值) =>
                    写(序(), {
                      ...填,
                      角色: 值 === null || 值 === 默认选项 ? undefined : 值,

  const [预览错误, 设预览错误] = createSignal<string>()
  const [预览中, 设预览中] = createSignal(false)

  const [关确认, 设关确认] = createSignal(false)

      设词表(回.value)
      const 初 = 行 === undefined ? 新表单(回.value) : 从行(行, 回.value)

    const 形 = 表单()

        >
          <div class="flex h-14 shrink-0 items-center gap-3 border-b border-v2-border-border-muted px-6">
            <Kobalte.Title class="min-w-0 flex-1 text-[16px] font-semibold text-v2-text-text-base">{标题()}</Kobalte.Title>
            <Kobalte.CloseButton
              type="button"
              aria-label="关闭"
              data-slot="card-template-close"
              class="flex size-7 items-center justify-center rounded-lg text-v2-icon-icon-muted hover:bg-v2-overlay-simple-overlay-hover"
            >

            </Show>
```

```tsx
    ? "shrink-0 rounded-[4px] bg-[var(--v2-background-bg-accent-soft)] px-1.5 py-0.5 text-[11px] font-semibold text-v2-text-text-base"
    : 态 === "已停用"
      ? "shrink-0 rounded-[4px] border border-v2-border-border-muted px-1.5 py-0.5 text-[11px] text-v2-text-text-muted line-through"
      : "shrink-0 rounded-[4px] border border-v2-border-border-muted px-1.5 py-0.5 text-[11px] text-v2-text-text-muted"

const 确认标题 = (类: 确认类): string => (类 === "转正" ? "转正这个模板？" : 类 === "停用" ? "停用这个模板？" : "恢复这个模板？")
const 确认按钮 = (类: 确认类): string => (类 === "转正" ? "确认转正" : 类 === "停用" ? "确认停用" : "确认恢复")

/**
 * 卡片模板列表（设计 §2 / §6）。分组：我的（启用中）/ 内置（只读）/ 已停用（折叠）。
 *
 * 所有判据来自行数据：`内置:` 前缀 = 只读；`disabled_at` = 已停用；`verified_at` 为空 = 未验证。
 * **状态用文字 + 颜色双通道**（设计 §7.3），不靠颜色单独表意。
 */
export function CardTemplates(props: CardTemplatesProps): JSX.Element {
  const 材料api = props.材料api ?? createCaseMaterialsApi()
  const [行们, 设行们] = createSignal<readonly 模板行[]>()
  const [载入, 设载入] = createSignal(true)
  const [错误, 设错误] = createSignal<string>()
  const [提示, 设提示] = createSignal<string>()
  const [展开停用, 设展开停用] = createSignal(false)
  const [抽屉, 设抽屉] = createSignal<抽屉>()
  const [待确认, 设待确认] = createSignal<{ 类: 确认类; 行: 模板行 }>()
  const [确认中, 设确认中] = createSignal(false)
  const [确认错误, 设确认错误] = createSignal<string>()
  const [确认跳过, 设确认跳过] = createSignal<Record<string, number>>()
  const [复核材料, 设复核材料] = createSignal("")
  const [材料们, 设材料们] = createSignal<readonly 材料视图[]>([])
  const [材料错误, 设材料错误] = createSignal<string>()

  async function 读() {
    设载入(true)
    设错误(undefined)
    const 回 = await props.api.list(props.projectId)
    设载入(false)
    if (回.kind === "error") {
      设错误(回.message)
      return
    }
    设行们(回.value)
  }

  onMount(() => {
    void 读()
    // 材料只用于「选一份已解析的做预览 / 复核」：失败只影响那两个下拉，不挡住模板列表。
    void (async () => {
      const 回 = await 材料api.read(props.projectId)
      if (回.kind === "error") {
        设材料错误(回.message)
        return
      }
      设材料们(回.value.materials.filter((项) => 项.status === "已解析"))
    })()
  })

  const 我的们 = () => (行们() ?? []).filter((行) => 是用户模板id(行.id) && 行.disabled_at === null)
  const 内置们 = () => (行们() ?? []).filter((行) => !是用户模板id(行.id))
  const 停用们 = () => (行们() ?? []).filter((行) => 是用户模板id(行.id) && 行.disabled_at !== null)
  const 本次复核 = () => (复核材料() !== "" ? 复核材料() : (材料们()[0]?.id ?? ""))

  function 打开确认(类: 确认类, 行: 模板行) {
    设确认错误(undefined)
    设确认跳过(undefined)
    设待确认({ 类, 行 })
  }

  function 关确认框() {
    设待确认(undefined)
    设确认错误(undefined)
    设确认跳过(undefined)
  }

  async function 执行确认() {
    const 目标 = 待确认()
    if (目标 === undefined) return
    设确认中(true)
    if (目标.类 === "转正") {
      const 材料 = 本次复核()
      if (材料 === "") {
        设确认中(false)
        设确认错误("请先选择一份已解析材料")
        return
      }
      const 回 = await props.api.verify({ projectId: props.projectId, id: 目标.行.id, materialId: 材料 })
      设确认中(false)
      if (回.kind === "error") {
        设确认错误(回.message)
        设确认跳过(回.跳过)
        return
      }
      关确认框()
      设提示(回.value.already === true ? "该模板已是验证状态" : `已转正（预览 ${回.value.卡片数} 张卡片）`)
      void 读()
      return
    }
    const 回 =
      目标.类 === "停用"
        ? await props.api.disable({ projectId: props.projectId, id: 目标.行.id })
        : await props.api.restore({ projectId: props.projectId, id: 目标.行.id })
    设确认中(false)
    if (回.kind === "error") {
      设确认错误(回.message)
      return
    }
    关确认框()
    设提示(目标.类 === "停用" ? "已停用" : "已恢复")
    void 读()
  }

  function 行视图(行: 模板行): JSX.Element {
    const 态 = 状态(行)
    return (
      <li
        data-slot="card-template-item"
        data-id={行.id}
        class="flex flex-wrap items-center gap-3 border-b border-v2-border-border-muted px-3 py-2 last:border-b-0"
      >
        <span data-slot="card-template-status" data-state={态} class={状态类(态)}>
          {态}
        </span>
        <span data-slot="card-template-name" class="text-[13px] font-semibold text-v2-text-text-base">
          {行.name}
        </span>
        <span data-slot="card-template-event" class="text-[12px] text-v2-text-text-muted">
          {行.event_type}
        </span>
        <span data-slot="card-template-hits" class="text-[12px] text-v2-text-text-muted">
          命中 {行.hit_count}
        </span>
        <div class="ml-auto flex items-center gap-1">
          <Show when={态 === "内置"}>
            <ButtonV2
              type="button"
              variant="ghost"
              size="small"
              data-slot="card-template-view"
              onClick={() => 设抽屉({ mode: "edit", 行, 只读: true })}
            >
              查看
            </ButtonV2>
          </Show>
          <Show when={态 === "已停用"}>
            <ButtonV2
              type="button"
              variant="ghost"
              size="small"
              data-slot="card-template-preview"
              onClick={() => 设抽屉({ mode: "edit", 行, 自动预览: true })}
            >
              预览
            </ButtonV2>
            <ButtonV2
              type="button"
              variant="ghost"
              size="small"
              data-slot="card-template-restore"
              onClick={() => 打开确认("恢复", 行)}
            >
              恢复
            </ButtonV2>
          </Show>
          <Show when={态 === "已验证" || 态 === "未验证"}>
            <ButtonV2
              type="button"
              variant="ghost"
              size="small"
              data-slot="card-template-edit"
              onClick={() => 设抽屉({ mode: "edit", 行 })}
            >
              编辑
            </ButtonV2>
            <ButtonV2
              type="button"
              variant="ghost"
              size="small"
              data-slot="card-template-preview"
              onClick={() => 设抽屉({ mode: "edit", 行, 自动预览: true })}
            >
              预览
            </ButtonV2>
          </Show>
          <Show when={态 === "未验证"}>
            <ButtonV2
              type="button"
              variant="ghost"
              size="small"
              data-slot="card-template-verify"
              onClick={() => 打开确认("转正", 行)}
            >
              转正
            </ButtonV2>
          </Show>
          <Show when={态 === "已验证" || 态 === "未验证"}>
            <ButtonV2
              type="button"
              variant="ghost"
              size="small"
              data-slot="card-template-disable"
              onClick={() => 打开确认("停用", 行)}
            >
              停用
            </ButtonV2>
          </Show>
        </div>
      </li>
    )
  }

  return (
    <section data-slot="card-templates" class="flex min-h-0 flex-1 flex-col gap-4 overflow-y-auto p-4">
      <header class="flex flex-wrap items-center gap-3">
        <h1 data-slot="card-templates-title" class="text-[16px] font-semibold text-v2-text-text-base">
          卡片模板
        </h1>
        <ButtonV2
          type="button"
          variant="contrast"
          size="small"
          class="ml-auto"
          data-slot="card-templates-create"
          onClick={() => 设抽屉({ mode: "create" })}
        >
          新建模板
        </ButtonV2>
      </header>

      <Show when={错误()}>
        {(话) => (
          <div role="alert" data-slot="card-templates-error" class="flex items-center gap-2 rounded-[4px] border border-v2-border-border-muted bg-v2-background-bg-layer-01 p-2 text-[12px] text-v2-state-fg-danger">
            <span class="min-w-0 flex-1">{话()}</span>
            <ButtonV2 type="button" variant="ghost" size="small" data-slot="card-templates-retry" onClick={() => void 读()}>
              重试
            </ButtonV2>
          </div>
        )}
      </Show>
      <Show when={提示()}>
        {(话) => (
          <p data-slot="card-templates-notice" role="status" class="text-[12px] text-v2-text-text-base">
            {话()}
          </p>
        )}
      </Show>
      <Show when={材料错误()}>
        {(话) => (
          <p data-slot="card-templates-material-error" class="text-[12px] text-v2-text-text-muted">
            材料清单读取失败（不影响模板列表）：{话()}
          </p>
        )}
      </Show>
      <Show when={载入() && 行们() === undefined}>
        <p data-slot="card-templates-loading" class="text-[13px] text-v2-text-text-muted">
          正在读取模板…
        </p>
      </Show>

      <Show when={行们()}>
        {() => (
          <>
            <section data-slot="card-templates-group" data-group="mine" class="flex flex-col gap-1">
              <h2 class="px-3 text-[12px] font-semibold text-v2-text-text-muted">我的模板</h2>
              <Show
                when={我的们().length > 0}
                fallback={
                  <p data-slot="card-templates-empty" class="px-3 text-[12px] text-v2-text-text-muted">
                    还没有自己建的模板。点「新建模板」建第一份。
                  </p>
                }
              >
                <ul class="rounded-xl border border-v2-border-border-muted">
                  <For each={我的们()}>{(行) => 行视图(行)}</For>
                </ul>
              </Show>
            </section>

            <section data-slot="card-templates-group" data-group="builtin" class="flex flex-col gap-1">
              <h2 class="px-3 text-[12px] font-semibold text-v2-text-text-muted">内置模板（只读）</h2>
              <Show
                when={内置们().length > 0}
                fallback={
                  <p data-slot="card-templates-empty-builtin" class="px-3 text-[12px] text-v2-text-text-muted">
                    本项目还没有内置模板
                  </p>
                }
              >
                <ul class="rounded-xl border border-v2-border-border-muted">
                  <For each={内置们()}>{(行) => 行视图(行)}</For>
                </ul>
              </Show>
            </section>

            <Show when={停用们().length > 0}>
              <section data-slot="card-templates-disabled-group" class="flex flex-col gap-1">
                <button
                  type="button"
                  data-slot="card-templates-disabled-toggle"
                  aria-expanded={展开停用()}
                  class="w-fit px-3 text-[12px] font-semibold text-v2-text-text-muted hover:text-v2-text-text-base"
                  onClick={() => 设展开停用(!展开停用())}
                >
                  {展开停用() ? "▾" : "▸"} 已停用的模板（{停用们().length}）
                </button>
                <Show when={展开停用()}>
                  <ul data-slot="card-templates-disabled" class="rounded-xl border border-v2-border-border-muted">
                    <For each={停用们()}>{(行) => 行视图(行)}</For>
                  </ul>
                </Show>
              </section>
            </Show>
          </>
        )}
      </Show>

      <Show when={抽屉()}>
        {(状) => (
          <CardTemplateEditor
            projectId={props.projectId}
            api={props.api}
            行={状().mode === "edit" ? 状().行 : undefined}
            只读={状().mode === "edit" ? 状().只读 === true : false}
            自动预览={状().mode === "edit" ? 状().自动预览 === true : false}
            材料们={材料们()}
            onClose={() => 设抽屉(undefined)}
            onSaved={() => {
              设抽屉(undefined)
              设提示(状().mode === "edit" ? "已保存" : "已新建")
              void 读()
            }}
          />
        )}
      </Show>

      <Show when={待确认()}>
        {(目标) => (
          <Kobalte open onOpenChange={(值) => { if (!值) 关确认框() }}>
            <Kobalte.Portal>
              <Kobalte.Overlay class="fixed inset-0 z-40 bg-v2-overlay-simple-overlay-scrim" />
              <Kobalte.Content
                data-slot="card-template-confirm"
                class="fixed top-1/2 left-1/2 z-50 max-h-[calc(100vh-4rem)] w-[min(30rem,calc(100vw-3rem))] -translate-x-1/2 -translate-y-1/2 rounded-2xl border border-v2-border-border-muted bg-v2-background-bg-base p-6 shadow-[var(--v2-elevation-overlay)]"
              >
                <Kobalte.Title class="text-[16px] font-semibold text-v2-text-text-base">
                  {确认标题(目标().类)}
                </Kobalte.Title>
                <div class="mt-3 flex flex-col gap-3 text-[13px] text-v2-text-text-base">
                  <Show when={目标().类 === "转正"}>
                    <p class="rounded-[4px] bg-v2-background-bg-layer-01 p-2 text-[12px] text-v2-text-text-muted">
                      转正后，这个模板产出的卡片才会进入 AI 的默认查询范围；现有卡片不会被改。
                    </p>
                    <label class="flex flex-col gap-1">
                      <span class="text-[12px] text-v2-text-text-muted">用哪份材料复核</span>
                      <SelectV2
                        data-slot="card-template-confirm-material"
                        appearance="large"
                        options={[...材料们()]}
                        current={材料们().find((项) => 项.id === 本次复核())}
                        value={(项) => 项.id}
                        label={(项) => 项.path}
                        placeholder="选择材料"
                        onSelect={(项) => {
                          if (项 !== null) 设复核材料(项.id)
                        }}
                      />
                    </label>
                  </Show>
                  <Show when={目标().类 === "停用"}>
                    <p>停用后：该模板不再参与自动选模板；已产出的卡片保留可追溯。可随时恢复。</p>
                  </Show>
                  <Show when={目标().类 === "恢复"}>
                    <p>恢复后：该模板重新参与自动选模板；验证状态保持不变。</p>
                  </Show>
                  <Show when={确认错误()}>
                    {(话) => (
                      <p data-slot="card-template-confirm-error" role="alert" class="text-[12px] text-v2-state-fg-danger">
                        {话()}
                      </p>
                    )}
                  </Show>
                  <Show when={确认跳过()}>
                    {(跳过) => (
                      <p data-slot="card-template-confirm-skip" class="text-[12px] text-v2-text-text-muted">
                        跳过：{Object.entries(跳过()).map(([原因, 数]) => `${原因} ${数}`).join(" · ")}
                      </p>
                    )}
                  </Show>
                </div>
                <div class="mt-4 flex justify-end gap-2">
                  <ButtonV2 type="button" variant="neutral" data-slot="card-template-confirm-cancel" onClick={关确认框}>
                    取消
                  </ButtonV2>
                  <ButtonV2
                    type="button"
                    variant="contrast"
                    data-slot="card-template-confirm-ok"
                    disabled={确认中() || (目标().类 === "转正" && 本次复核() === "")}
                    onClick={() => void 执行确认()}
                  >
                    {确认中() ? "处理中…" : 确认按钮(目标().类)}
                  </ButtonV2>
                </div>
              </Kobalte.Content>
            </Kobalte.Portal>
          </Kobalte>
        )}
      </Show>
    </section>
  )
}
```

```tsx
  test("模板路径 ⇒ 渲染卡片模板列表（api 可注入，页面里不建真客户端）", async () => {
```

   - 未验证：刚建好，**还没被算法确认过**，不会进入 AI 的默认查询范围；
   - 已验证（转正）：用一份真材料跑过、产出了卡片，系统才信它；

   - 「同类型下已有启用中的用户模板」→ 去「我的模板」把旧的停用，再保存/恢复；

6. **边界**：模板只决定「哪一列映射到哪个槽」；金额方向、时间解析、单位换算由系统负责，模板改不了。
