# 蜂巢 OpenHive Logo 规范

- **日期**：2026-09-06
- **状态**：定稿
- **主题**：蜂巢 logo（图形标 + 文字标）的字体、颜色、尺寸、间距、几何构造规范
- **源文件**：本目录下 `logo-mark.svg`（图形标）、`logo-light.svg`（浅色底完整版）、`logo-dark.svg`（深色底完整版）
- **关联**：`2026-09-06-蜂巢前端设计建议.md`（§4 Logo 定稿）

## 1. 构成总览

logo 由两部分组成：

```
[图形标]  OpenHive  [蜂巢]
六边形+蜂窝  粗体    圆角标签
```

| 部分 | 说明 | 文件 |
|---|---|---|
| 图形标 | 外六边形描边 + 中心实心渐变蜂窝 | `logo-mark.svg`（独立），`logo-light/dark.svg`（内嵌缩小版） |
| 文字标 | 「OpenHive」粗体 + 「蜂巢」圆角标签 | `logo-light.svg` / `logo-dark.svg` |

## 2. 颜色规范

### 2.1 品牌色（蜂蜜金三档）

| 名称 | 色值 | 用途 |
|---|---|---|
| 品牌浅金 | `#F59E0B` | 蜂窝渐变起点、标签底色、深色版描边/文字 |
| 品牌主金 | `#D97706` | 外六边形描边（浅色版）、「蜂巢」文字色 |
| 品牌深金 | `#B45309` | 蜂窝渐变终点 |

### 2.2 蜂窝渐变

```
线性渐变，方向：垂直（上 → 下）
起点（0%）  #F59E0B
终点（100%）#B45309
```

### 2.3 文字色（随底色版本变化）

| 元素 | 浅色底（light） | 深色底（dark） |
|---|---|---|
| 「OpenHive」 | `#1C1A18`（暖黑） | `#FFFFFF`（白） |
| 「蜂巢」文字 | `#D97706`（主金） | `#F59E0B`（浅金） |
| 外六边形描边 | `#D97706` | `#F59E0B` |
| 「蜂巢」标签底色 | `#F59E0B` @ 12% 透明度 | `#F59E0B` @ 20% 透明度 |

> 深色版整体比浅色版**提亮一档**：描边、文字、标签都用浅金 `#F59E0B`，保证在深色背景上的对比度。

## 3. 字体规范

| 元素 | 字体 | 字号 | 字重 |
|---|---|---|---|
| 「OpenHive」 | `PingFang SC, Microsoft YaHei, sans-serif` | 24px | 700（粗体） |
| 「蜂巢」 | 同上 | 13px | 600（半粗体） |

- **只用系统字体栈**（PingFang SC / Microsoft YaHei），不加载自定字体、不用 Google Fonts（内网不通）。
- 「OpenHive」与「蜂巢」均 **`dominant-baseline: central` 垂直居中**。

---

## 4. 几何构造（图形标）

### 4.1 等边六边形（核心约束）

- **必须是严格等边六边形，六条边等长**。
- 朝向：**flat-top（上下尖）**，正上、正下各一个顶点。
- **构造方法（防变形）**：顶点用程序精确计算，不能手写坐标取整。

```
中心 (cx, cy)，外接圆半径 R，6 个顶点（角度从 -90° 起，每 60° 一个）：
  顶点 i: x = cx + R·cos(-90° + 60°·i)
          y = cy + R·sin(-90° + 60°·i)
```

### 4.2 尺寸参数

| 版本 | 画布 | 外六边形 R | 外描边宽 | 中心蜂窝 R |
|---|---|---|---|---|
| `logo-mark.svg` | 200×200 | 90 | 9 | 34 |
| `logo-light/dark.svg` | 340×64 | 24 | 5 | 9 |

- 中心蜂窝 = 同圆心、同朝向的**缩小等边六边形**（半径约为外六边形的 0.375 倍）。

## 5. 文字标排版

### 5.1 布局参数（logo-light / logo-dark，画布 340×64）

| 元素 | 位置 | 尺寸 |
|---|---|---|
| 图形标中心 | (32, 32) | 外 R=24，描边 5 |
| 「OpenHive」 | x=70 起，垂直居中 y=32 | 24px / 700 |
| 「蜂巢」标签框 | x=197.5，y=21 | 宽 44，高 22，圆角 rx=6 |
| 「蜂巢」文字 | 框中心 (219.5, 32) | 13px / 600，水平+垂直居中 |

### 5.2 间距规范

- **标签框与「OpenHive」末尾字母间隔 8px（约 2mm）**。
- 「OpenHive」粗体 24px 实测渲染宽度 ≈ **119.5px**（PingFang/YaHei 下），右边缘 ≈ x=189.5，标签框左边缘 = 189.5 + 8 = 197.5。

> ⚠️ **SVG 的限制**：SVG 里文字宽度随字体渲染浮动（±1~2px），无法精确保证 8px 间距。**转 React 组件后必须改用 flexbox `gap: 8px` 精确控制**，不再硬编码坐标。

## 6. 使用规范

| 场景 | 用哪个 |
|---|---|
| 主界面、浅色背景、文档 | `logo-light.svg` |
| 登录页、深色背景、深色顶栏 | `logo-dark.svg` |
| favicon、侧边栏小图标、纯图形 | `logo-mark.svg` |

- **最小尺寸**：图形标（外六边形 + 蜂窝）在小尺寸下蜂窝会变糊，favicon 场景可考虑只保留外六边形描边。
- **安全间距**：logo 四周预留至少 1/4 图形标高度的留白，避免与其他元素拥挤。
