# Cloudflare OS（deploy 页）设计风格拆解

- **日期**：2026-09-06
- **状态**：存档
- **主题**：从设计哲学、视觉语言、组件模式、信息设计、可访问性五个维度，拆解 Cloudflare OS 部署落地页（`https://os.cloudflare.app/deploy`）的设计风格
- **方法**：基于浏览器实测的真实 DOM/CSS 值，非视觉猜测
- **边界说明**：`deploy` 是部署落地页（表单式向导），非登录后的产品主界面。本报告针对「Cloudflare 品牌设计语言 + 工具型产品落地页风格」，主界面组件待补充。

---

## 一、设计哲学

| 维度 | 判断 | 依据 |
|---|---|---|
| 品牌调性 | **工程工具型 + 克制专业**，不带消费级花哨 | 全页几乎无装饰色块、无渐变、无 emoji 堆砌 |
| 目标用户 | **开发者 / 技术决策者** | 文案直给「Workers、KV、R2、API key」等云原生术语，默认读者懂部署 |
| 情感传达 | **可信、高效、不打扰** | 页面极简，把「会发生什么」列清楚（三步），降低部署焦虑 |

Cloudflare 的设计 DNA 是「**让复杂的东西看起来可控**」——这个 deploy 页把「一整套 Serverless 资源编排」包装成「填个名字、填个邮箱、点一下」的轻量流程。

## 二、视觉语言（基于真实 CSS 值）

| 维度 | 精确值 | 解读 |
|---|---|---|
| 背景色 | `#FCFCFB`（暖白，非纯白） | 比纯白略暖，柔和不刺眼 |
| 主文字 | `#1C1A18`（近黑，带暖调） | 高对比，稳重 |
| 品牌/强调色 | `#FF4801`（Cloudflare 标志橙） | 唯一的高饱和色，只用在 CTA 和链接，非常克制 |
| 主字体 | `FT Kunst Grotesk`（Cloudflare 定制无衬线） | 自有字体，识别度高 |
| H1 | 30px / 600 / line-height 36px | 大标题但不夸张 |
| H2 | 18px / 500 / 28px | 层级清晰，次标题沉稳 |
| 正文 | 16px / 400 / 24px | 行高 1.5，阅读舒适 |
| 链接 | `#FF4801` / 12px / 500 | 橙色小字，弱化但可识别 |

**排版节奏**：字号阶梯（30→18→16→14→12）干净利落，没有中间模糊档。字重只用 400/500/600 三档，不堆粗体。

**布局节奏**：左对齐单列流，大留白，无多栏堆叠。页面重心在「表单」，没有视觉噪音抢注意力。

## 三、组件与模式

| 组件 | 真实样式 | 特征 |
|---|---|---|
| 主 CTA 按钮 | `#FF4801` 实心橙底 / 白字 / **8px 圆角** / 14px / padding 10×20 | 圆角克制（8px 不是全圆），实心高饱和，全页唯一强视觉焦点 |
| 输入框 | 白底 / **8px 圆角** / 1px 边框 `rgba(20,17,16,0.06)` / 14px | 边框极淡（6% 黑），靠留白而非描边区分 |
| 次级按钮（如 Custom domain） | 透明底 / 文字式 | 弱化，符合「主次分明」 |
| 步骤说明 | 「图标 + 标题 + 描述」三段式 | 用图标做视觉锚点，文字说明做什么 |

**布局模式**：经典「**单列表单落地页**」——品牌 → 标题 → 表单分组（实例名 / 邮箱 / 模型 key）→ 状态区。每组一个 H2 带描述，层次非常清晰。

## 四、内容与信息设计

- **内容优先级**：通过「字号 + 字重 + 颜色」三级区分，H1 是唯一大标题，CTA 是唯一彩色块，其余全部中性色。
- **文案策略**：每个输入框都有「一句话说明 + 约束提示」（如「Lowercase letters, digits, and dashes」），把「会不会填错」的焦虑前置化解。
- **数据可视化**：此页**无图表**——它是纯表单流，用「文字步骤」而非图形。这本身是个信号：Cloudflare 该用图时才用图，不为了好看硬塞图表。
- **可选项折叠**：「Custom domain」「Advanced」用可折叠按钮收起，默认只暴露核心字段，符合渐进披露。

## 五、可访问性

| 项 | 评估 |
|---|---|
| 色彩对比度 | 主文字 `#1C1A18` 对 `#FCFCFB` ≈ **15:1**（远超 WCAG AAA 7:1），非常优秀 |
| CTA 对比度 | 白字对橙底 `#FF4801` ≈ **3.3:1**，对大字（14px 加粗）达到 AA，属可接受但非最优 |
| 焦点状态 | 需实测 Tab 键，但从「border 极淡」推断，焦点态可能依赖浏览器默认 outline，有待验证 |
| 字号 | 最小 12px，正文 16px，符合移动可读性 |

## 设计风格速查清单（Design Style Cheatsheet）

| 属性 | 值 |
|---|---|
| 主背景 | `#FCFCFB`（暖白） |
| 主文字 | `#1C1A18`（暖黑） |
| 品牌色 | `#FF4801`（Cloudflare 橙） |
| 辅助/边框 | `rgba(20,17,16,0.06)`（6% 黑） |
| 主字体 | FT Kunst Grotesk（无衬线） |
| H1 / H2 / 正文 | 30px-600 / 18px-500 / 16px-400 |
| 圆角 | **8px**（统一，克制） |
| 按钮 | 实心橙 + 白字，透明次级按钮 |
| 布局 | 单列表单流，大留白 |
| 图标 | 线性 + 文字说明 |
| 动效 | 极简（无明显动画） |

## Pros（正面可借鉴点）

| # | 可借鉴点 |
|---|---|
| 1 | **单一品牌色纪律**：全页只有橙一个彩色，焦点集中在 CTA，不花哨 |
| 2 | **极淡边框**（6% 黑）+ 大留白，用空间而非线条分隔，高级感来源 |
| 3 | **8px 统一圆角**：克制，不追求全圆角潮流 |
| 4 | **渐进披露**：可选项折叠，默认只暴露核心字段 |
| 5 | **前置化解焦虑**：每个输入框都有约束提示，降低填错率 |
| 6 | **对比度 15:1**：正文可读性极佳 |

## Cons（潜在改进点）

| # | 改进点 |
|---|---|
| 1 | **CTA 对比度偏弱**（3.3:1），橙色底 + 白字在低亮度屏上可读性一般，可加深橙或改深色字 |
| 2 | **焦点状态不明**：极淡边框可能让键盘用户看不清当前焦点，需明确的 focus ring |
| 3 | **纯表单无视觉锚点**：长表单页面缺一张「成品预览图」，用户看不到部署完长什么样，可加截图降低不确定性 |
| 4 | **动效几乎为零**：对「部署中/完成」这种状态切换，缺一点过渡反馈 |
