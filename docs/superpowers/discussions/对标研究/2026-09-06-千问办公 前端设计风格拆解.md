# 千问办公（QwenWork）主界面设计风格拆解

- **日期**：2026-09-06
- **状态**：存档
- **主题**：从设计哲学、视觉语言、组件模式、信息设计、可访问性五个维度，拆解千问办公产品主界面（`https://qwenwork.cn/app/` 的「新任务」首页）
- **方法**：基于浏览器实测的真实 DOM/CSS 值
- **边界说明**：拆解对象为「新任务」首页（未登录可见）。对话结果页、文档编辑页、专家套件页等更深界面待补充。

---

## 一、设计哲学

| 维度 | 判断 | 依据 |
|---|---|---|
| 品牌调性 | **极简中性风 + 高信任感**，几乎无品牌色 | 全页黑白灰，唯一「色彩」靠文字和阴影 |
| 目标用户 | **普通办公白领（非技术）** | 界面只有「新任务/专家套件/技能/连接器」等业务词，零技术术语 |
| 情感传达 | **安静、专注、不施压** | 首屏是一句问候「晚上好，朋友」+ 一个大输入框，像聊天而非操作台 |

千问办公的设计哲学是「**去工具感，向对话靠近**」——它把「AI 办公」包装成「一个懂你的助手在等你开口」，而不是「一个功能密集的软件」。这和 Cloudflare 的「工程工具感」形成鲜明对比。

## 二、视觉语言（基于真实 CSS 值）

| 维度 | 精确值 | 解读 |
|---|---|---|
| 背景色 | `#FCFCFC`（近白） | 中性白，干净 |
| 主文字 | `#141414`（近纯黑） | 高对比 |
| **品牌/强调色** | **无独立品牌色**，强调靠 `rgba(20,20,20,0.07)` 灰底 | 极端克制的「黑白灰」策略 |
| 字体 | `system-ui` + PingFang SC / Microsoft YaHei（中文字体栈） | 用系统字体，不加载自定字体（加载快） |
| H1 问候 | 24px / 600 / 32px | 「晚上好，朋友」克制但亲切 |
| 正文 | 16px / 400 / 24px | 标准 |
| 导航按钮 | 13px | 小字，弱化 |

**核心视觉特征：靠「阴影」而非「颜色」分层。** 输入框容器是唯一的重视觉元素——`boxShadow: 1px 描边 + 0 16px 48px -8px` 的大柔和投影，浮在近白背景上。这是「无边框设计 + 阴影分层」的典型。

## 三、组件与模式

| 组件 | 真实样式 | 特征 |
|---|---|---|
| **主输入框（Hero 输入卡片）** | 白底 `#FFF` / **24px 大圆角** / 阴影 `0 0 0 1px + 0 16px 48px` / 最小高 118px | 全页视觉中心，像个「对话气泡放大版」，不是传统表单 |
| 「新任务」按钮 | 灰底 `rgba(20,20,20,0.07)` / 10px 圆角 / 无边框 | 弱化，带 `Ctrl+K` 快捷键提示 |
| 推荐提示词按钮 | 透明底 / 12px 圆角 / 13px 文字 `rgba(20,20,20,0.65)` | 一行行可点文字，像「可点的话题」而非按钮 |
| 侧边栏导航 | 透明底 / 13px | 极简，靠文字和图标区分，无底色块 |

**布局模式**：经典「**AI 助手首页**」——左侧窄导航栏（扩展/定时任务/我的网页/个人网盘），中间垂直居中的「问候 + 大输入框 + 推荐提示词」。首屏留白极大，把注意力全部引到「输入框」这一个动作上。

## 四、内容与信息设计

- **内容优先级**：极度聚焦——首屏只有「问候」「输入框」「推荐提示词」三样，其余功能全收进侧边栏，默认不打扰。
- **引导策略**：用「推荐提示词」按钮（周报/表格/演示文稿）降低「不知道问什么」的冷启动门槛，这是 AI 产品的通用解法。
- **数据可视化**：首页无图表（它是任务发起页）。图表能力在「专家套件/技能」里，首页不提前展示。
- **渐进披露**：所有高级功能（专家套件、连接器、定时任务）都藏在侧边栏二级，首页保持纯净。

## 五、可访问性

| 项 | 评估 |
|---|---|
| 色彩对比度 | 主文字 `#141414` 对 `#FCFCFC` ≈ **17:1**，极优（AAA） |
| 推荐提示词 | `rgba(20,20,20,0.65)` 对白底 ≈ **6.5:1**，接近 AAA |
| 输入框描边 | 用 50% 透明度黑做 1px 描边 + 阴影，弱但可辨 |
| 焦点状态 | 输入框有明确的 focus 态（由阴影/描边强化），符合预期 |
| 无颜色依赖 | 纯黑白灰，不依赖颜色区分信息，色弱友好 |

| 属性 | 值 |

| 字体 | system-ui + PingFang SC / Microsoft YaHei |
| H1 / 正文 | 24px-600 / 16px-400 |

| 按钮 | 10px 圆角灰底 / 透明文字式 |
| 布局 | 左导航 + 居中 Hero 输入区 |
| 视觉分层 | **靠阴影，不靠颜色** |

## Pros（正面可借鉴点）

| # | 可借鉴点 |
|---|---|
| 1 | **无品牌色纪律**：黑白灰 + 阴影分层，视觉噪音极低，注意力全在内容 |
| 2 | **Hero 大输入框**：24px 圆角 + 柔和投影，把「对话」这个核心动作做成视觉中心 |
| 3 | **冷启动引导**：推荐提示词降低「不知道问啥」的门槛 |
| 4 | **渐进披露**：高级功能全收进侧边栏，首页纯净 |
| 5 | **系统字体**：不加载自定字体，加载快、跨平台一致 |
| 6 | **对比度 17:1**：可读性拉满 |

## Cons（潜在改进点）

| # | 改进点 |
|---|---|
| 1 | **品牌辨识度弱**：纯黑白灰 + 系统字体，无记忆点，容易被误认为「又一个 ChatGPT 克隆」 |
| 2 | **侧边栏信息层级平**：扩展/技能/连接器/定时任务平铺，无分组轻重，新手可能困惑 |
| 3 | **「新任务」按钮太弱**：7% 灰底几乎看不见，核心入口的视觉权重可能不足 |
| 4 | **首屏功能单一**：除了发任务，看不出「它能交付什么成果」（缺成果展示/样例），信任感建立慢 |
| 5 | **问候语「朋友」偏随意**：在严肃办公场景，口语化称呼可能削弱专业感 |

## 与 Cloudflare OS 的对比（一句话）

| | Cloudflare OS | 千问办公 |
|---|---|---|
| 设计哲学 | 工程工具型、专业克制 | 对话助手型、安静专注 |
| 色彩 | 有品牌橙 `#FF4801` 做 CTA | 无品牌色，纯黑白灰 |
| 视觉分层 | 极淡边框 + 留白 | 阴影浮起 |
| 圆角 | 8px（克制） | 24px（大圆角，柔和） |
| 目标用户 | 开发者 | 普通白领 |

两者代表了 AI 产品设计的两极：**Cloudflare 靠「品牌色 + 克制圆角」立专业感，千问靠「无彩色 + 大圆角 + 阴影」立亲和感**。
