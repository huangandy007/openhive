## 任务格式约定

- `[P]` = 可并行（不同文件、无依赖）

- `[FE]` 任务标注「换皮」或「新增」：**换皮** = 改 opencode 已有组件 token；**新增** = 新建 openhive 组件（资金树 / 四视图 / 图谱画布）。token 映射见 plan.md「前端换皮区」。
- 每条含 `[FR-x 来源] [依赖任务] [出参验证方式]`
