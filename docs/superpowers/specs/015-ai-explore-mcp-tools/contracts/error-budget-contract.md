# Contract · 错误码与预算

**Feature**: `015-ai-explore-mcp-tools` · **Version**: 1（2026-11-17）

实现唯一出处：`packages/opencode/src/server/openhive/case-mcp-server.ts`（门链 :827-886，预算 :137-165）。

## 1. 错误形状

```json
{ "error": "bad_input", "message": "不认识的参数：起始时间；可用参数：起、止、账户、方向、对手、含未验证" }
```

- 以 `isError: true` 的 MCP 结果返回（`失败结果`，:790）。
- `message` 可以被人读；**不得含 SQL、堆栈、表名**。

## 2. 九个码与触发面

| 码 | 触发 | 前端引导（`09` §8.3 逐字，不是服务端 message） |
|---|---|---|
| `bad_input` | 参数键白名单外 / 类型错 / 缺必填 | 参数不对，我再试一次 |
| `not_found` | 实体 / 文件 / 档案不存在 | 没找到这个实体 |
| `not_a_member` | 调用者不是该项目成员 | 无权访问该项目 |
| `forbidden` | 写工具调用者不是属主 | 只有项目属主能改 |
| `too_many` | 图工具批量超限 | 一次给太多，请分批 |
| `ambiguous_path` | 图工具未点名且项目有多张图 | 请先列图，再点名 |
| `write_failed` | 图写盘 / 读回失败 | 写进去了但读不回来（**不许**说成「没写」） |
| `tool_failed` | 工具内部异常 / 信封违约 | 保持固定中文「工具执行失败，已记入服务端日志」（:718） |
| `unknown_tool` | 工具名不在 19 个之内 | 没有这个工具 |

> 服务端 `message` 字段由各工具自拟；前端**只**用码查引导，不解析 message。

**铁律**：`tool_failed` 的具体原因**只进留痕**，不回给模型（防内部细节外泄）。

## 3. 门链（顺序不可调）

| 步 | 动作 | 落点 | 失败码 |
|---|---|---|---|
| ① | 解析调用身份（`_meta`） | :827-833 | `身份错误.code` / `tool_failed` |
| ② | 校验项目成员 | :837-843 | `not_a_member` |
| ②b | 写工具校验属主（`写工具名` 7 个） | :845-856 | `forbidden` |
| ③ | 工具名判定 | :858-859 | `unknown_tool` |
| ④ | 必填校验 → 预算计次 → 分发 | :861-868 | `bad_input` / 工具码 / `tool_failed` |

**为什么 ② / ②b 在名字分发之前**：未知工具名、无权限工具都不得成为探路侧信道（:837 / :845 注释）。

## 4. 预算

| 属性 | 值 / 行为 |
|---|---|
| 上限 | `预算上限 = 12`（:139） |
| 窗口 | `预算窗口毫秒 = 10 * 60 * 1000`，**空闲滑窗**：距最后一次调用满 10 分钟无新调用 ⇒ 下次从 1 重计（:158 严格小于判断） |
| 键 | `${userId}\u0000${projectId}`（:154） |
| 返回 | `计次` 返回**本次是第几次**（1 起） |
| 注入点 | 成功分支：信封工具追加到 `缺口` 末尾（:882）；图工具写成显式字段 `预算上限缺口`（:872） |
| 注入条件 | `第几次 >= 12` ⇒ **第 12 次即注入**，之后每次注入 |
| 不计数 | 未知工具（③ 提前 return）、必填缺失（`校验必填` 先于计次） |
| 不注入 | 失败返回（含 `too_many` / `bad_input` 等） |
| 拦截 | **从不拦截**；第 13 次起照常执行 |
| 文案 | 固定 `近 10 分钟内查询已达 12 次，必须收尾并列出未覆盖项`（:142），**不许**改写成「本次探索」 |
| 实例 | 生产单例 `默认预算`（:168），必须活在 server 之外；每请求新建 server 不得重置计数 |

## 5. 留痕

- 每次调用（成功 / 业务错误 / 门拒 / 未知工具 / 异常）**恰好一行** JSON 到 stderr（`记`，:815-825）。
- 字段：`userId? / projectId? / 工具 / 耗时毫秒 / ok / 错误码? / 错误原文?`。
- 身份未解出时**不编假身份**（`userId` / `projectId` 可缺）。
- 这是排障日志，**不是**表级使用记录，不得拿来当审计账。

## 6. 前端消费（本期）

- 错误卡显示：`错误码` + `message` + 一句「人话引导」（9 码映射见 `../research.md` D3）。
- 未知码：只显示原码与原文，**不伪造**引导。
- `预算上限缺口`：工具卡按 `缺口` 项正常展示；收尾行不重复展示。
