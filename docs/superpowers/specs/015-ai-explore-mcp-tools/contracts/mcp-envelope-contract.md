# Contract · MCP 信封

**Feature**: `015-ai-explore-mcp-tools` · **Version**: 1（2026-11-17）

本契约是**模型与前端共同消费的对外形状**。工具名、字段名、空原因字面值都按字面读取，改动即破坏契约。

## 1. 传输与形状

- 传输：MCP `tools/call` 结果。
- 成功：`content[0].text` 是一个 JSON 字符串，内容为**一个**信封对象。
- 失败：`isError: true`，`content[0].text` 为 `{ "error": <码>, "message": <文本> }`（见 `error-budget-contract.md`）。
- 信封字段：`摘要 / 数据 / 口径 / 缺口 / 空原因 / 出处 / 下一步`（+ 可选 `身份`）。逐字段类型与校验规则见 `../data-model.md` §1。

## 2. 工具清单与是否套信封

| 类别 | 工具名 | 套信封 |
|---|---|---|
| 原子（7） | `search_materials`、`query_entities`、`query_relations`、`query_events`、`aggregate_money`、`find_crossings`、`get_citation` | ✅ |
| 原语（4） | `query_rows`、`query_timeline`、`explore_entity`、`money_flow` | ✅ |
| 数据源档案（3） | `list_source_profiles`、`build_source_profile`、`revoke_source_profile` | ✅ |
| 图 读（2） | `graph_list`、`graph_read` | ❌（图结果原样） |
| 图 写（3） | `graph_add`、`graph_update`、`graph_remove` | ❌（写结果原样） |

合计 19 个工具（14 信封 + 5 图）。**图工具不套信封**，但计入预算；被预算挡下时在自身结果里带 `缺口` 字段（`预算上限缺口`）。

## 3. `空原因` 契约

- 取值限于 16 枚举（`case-envelope.ts:37-54`），顺序即优先级，**只报第一个成立的**，其余进 `缺口`。
- 双向镜像：`空原因` 非 null ⇔ `数据` 为空（`null` 或 `[]`）。违反 ⇒ `tool_failed`。
- **归属纪律**：每个值只有一个归属工具，借值即错（`09` §3.5；spec FR-004 / Clarifications Q1）。

已核实的工具字面值（`case-mcp-tools.ts` grep 结果，2026-11-17）：

| 工具 | 报出的值 |
|---|---|
| `explore_entity` | `无此实体`、`实体存在但无任何事实`、`材料未解析` |
| `query_entities` | `项目内资金材料未翻译` |
| `query_events` | `能力未就绪`、`用途未结构化` |
| `query_relations` | `实体没有关联账户`（`判关系空原因` :646）、`无匹配行` |
| `query_timeline` | `对象未登记`（:1305）、`能力未就绪` |
| `money_flow` | `项目内资金材料未翻译`、`确实没有交易`、`实体没有关联账户`、`账户未在材料中出现`、`外币行全部未计入`（spec US2） |
| 其余信封工具 | 缺省兜底 `无匹配行` |

> `对象未登记` **只许** `query_timeline` 使用（:2906 注释明确其他工具用 `无匹配行`）。完整逐值归属以 `09` §3.5 总表为权威；运行期由 16 值枚举校验兜底。

## 4. 条数与字节上限

| 约束 | 值 | 行为 |
|---|---|---|
| `限制` 默认 | 50 | 未传时生效 |
| `限制` 上限 | 200 | 超上限**截断**，不报错 |
| 单次 `数据` 序列化 | 30 KB | 从尾部按条截；条数写进 `缺口`；非数组超限也必须写缺口 |

分页：`query_rows` / `query_timeline` 用 `游标` 续页；有下一页时**不报**「全外币」类空原因。

## 5. `出处` / `下一步`

- `出处项 = { 事实, 代表, 可下钻 }`；`代表` 是 `材料#工作表#行号` 或事实 id；`可下钻` 为 null 表示没有更细出口。
- `下一步项 = { 工具, 参数, 为什么 }`；**服务端与前端都不自动执行**；一期前端只展示、不可点击。

## 6. 兼容性规则

- 新增字段：允许（消费方必须忽略未知键）。
- 改字段名 / 改枚举字面值 / 改工具名：**破坏性**，必须同时改 spec、契约、用例与前端解析。
- 删除 `缺口` / `空原因` 的可见性：**禁止**（规格 US3 要求必显）。
