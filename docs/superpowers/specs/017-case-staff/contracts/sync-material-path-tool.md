# 契约 · 案件 MCP 工具 `sync_material_path`（017-case-staff 修复）

> 背景：材料行的身份是 `(project_id, fingerprint)`，文件树的「已解析」徽标却按
> `case_material.path` 精确匹配。文件若在平台外被移动，路径分家 ⇒ 已入库的文件在新位置
> 显示成「未入队」。本工具按内容指纹把材料行重新关联到它现在所在的位置。

---

## 1. 工具与参数

| 项 | 值 |
|---|---|
| name | `sync_material_path` |
| 入参 | `路径`：文件**现在**的项目相对路径，`/` 分隔 |
| 返回 | 七字段信封（`摘要 / 数据 / 口径 / 缺口 / 空原因 / 出处 / 下一步`） |
| 门槛 | 身份门 → 成员门（与取数工具同层）；工具内补归档冻结（`ProjectMembership.frozen`） |
| 文件根 | 恒按**属主**拼（`项目属主` + `projectDirectory`），与 `move_material` 同一条判据 |

`写工具名`：**不加**。理由与 `move_material` 相同——移动/改名是成员级操作，
本工具只补做同一件事的记账部分，不应出现「UI 能移、AI 不能」的第二套口径。

---

## 2. 语义（按序）

1. 项目已归档 ⇒ `forbidden`。
2. `inside(项目根, 路径)`；顶层必须是 `材料/`；拒绝 `材料/00-材料登记表.md`。
3. `inGitOf` ⇒ `bad_input(GIT_LOCKED)`。
4. `lstat` 必须是**已存在的普通文件**；`realInside(项目根, dirname)` 防链接逃逸。
5. 读盘、算 `Hash.sha256(文件字节)`（与入库指纹同一口径）。
6. 按 `(project_id, fingerprint)` 找材料行：
   - 没有 ⇒ 回空信封，`空原因 = 材料未入库`；**不新建材料行、不动文件**。
   - 有且 `path` 已等于入参 ⇒ `已变更 = false`，原样返回 `解析状态`，不写库。
   - 有且路径不同 ⇒ 调 `迁移材料路径`（同一事务内改材料行 + 排队中作业的 `source_path`）。
7. **不搬文件、不改名、不改 `parse_status`、不重解析。**

---

## 3. 返回数据

```json
{
  "数据": [
    {
      "材料id": "…",
      "文件名": "流水.xlsx",
      "旧路径": "材料/00-待归档/流水.xlsx",
      "新路径": "材料/06-话单与资金/资金/张三/流水.xlsx",
      "解析状态": "已解析",
      "已变更": true
    }
  ]
}
```

- `已变更=true`：路径已改好；`false`：本来就一致，或 `迁移材料路径` 失败。
- `迁移材料路径` 失败不回滚文件（文件根本没动），`缺口` 写明原因，`已变更=false`。
- 未找到材料行时 `数据=[]`、`空原因="材料未入库"`、`出处=[]`。

---

## 4. 错误码

| code | 触发 |
|---|---|
| `forbidden` | 项目已归档 |
| `bad_input` | 路径越界 / 非 `材料/` / 登记表 / 版本库元数据 / 不存在 / 非普通文件 / 链接逃逸 / 读盘失败 |
| `not_a_member` / `identity_required` | 服务入口既有门 |
| `tool_failed` | 其他异常（原文只进留痕） |

## 5. 用例（`packages/opencode/test/server/openhive-case-mcp-move.test.ts`）

| # | 场景 | 期望 |
|---|---|---|
| 15 | 文件在平台外被移动，材料行仍指旧路径且 `已解析` | 路径改指新路径，`解析状态` 仍 `已解析`，文件未再移动 |
| 16 | 平台没有同指纹材料行 | 空原因 `材料未入库`，不新建行 |
| 17 | 记录路径已一致 | `已变更=false`，解析状态照旧返回 |
| 18 | 非 `材料/` / 目录 / 不存在 | `bad_input`，零副作用 |

服务注册与描述三段式在 `openhive-case-mcp-server.test.ts`；工具覆盖守卫在
`openhive-case-mcp-tools.test.ts` 的「所有工具返回的下一步 / 出处.可下钻」用例。

---

## 6. 技能侧约定

- 归档：`move_material` 之后逐份调 `sync_material_path`，把 `数据[0].解析状态` 写进回执。
- `move_material` 不在工具清单 ⇒ **停止归档**，不得改用 shell 移动。
- 标志丢失时先修路径，不点「重新解析」。
