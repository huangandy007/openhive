# 契约 · 文件格式的读写边界（`.hgraph`）

**字段语义与字段表在 [`../data-model.md`](../data-model.md) §1–§6，本文件不重复**。这里只定「什么算合法读、什么算合法写、拒绝时回什么」，供纯函数用例（TR-002）与实现直接对照。

## 1. 读（解析）

| 输入 | 结果 |
|---|---|
| 合法 JSON 且 `格式 === 1` | `{ ok: true, 文档, 原文树 }`（`原文树` 保留全部未知键） |
| `格式` 缺失或非 1 | `{ ok: false, code: "BAD_VERSION", 说明: "这份图的格式版本不认识（读到 X），请升级后再打开" }` ⇒ 只读打开 |
| `格式 > 1` | `{ ok: false, code: "NEWER_VERSION", … }` ⇒ 只读打开 + 提示升级 |
| JSON 解析失败 | `{ ok: false, code: "BAD_JSON", 说明: "这份图打不开：<位置> 附近不是合法 JSON" }` ⇒ **禁止一切写回**（含 AI） |
| 顶层不是对象 / `节点`、`边`、`文字` 不是数组 | `{ ok: false, code: "BAD_SHAPE", 说明: "第 N 个节点缺了 id" 这类可定位的话 }` |
| 未知键（顶层或对象内） | **合法**，原样保留 |
| `类型` 不在任何已知表里 | **合法**，默认形状显示 |
| 引用不存在的节点 id 的边 | 读时**不丢弃**、不自动修：标记该边为「悬空」，界面画成灰色虚线并在检查器说明（不静默改文件） |

> 读失败 ⇒ **只读模式**：编辑器禁用一切写入口，AI 工具对这个路径返回 `not_found`/`bad_input`（不许「先修好再写」）。

## 2. 写（校验）

写入前对**每个**待写对象跑下面这张表；任一不过 ⇒ 整批拒绝，文件字节不变。

| code | 触发 | 给用户/AI 的原话 |
|---|---|---|
| `FACTS_NEED_SOURCE` | `性质 = 事实` 的边，`出处` 与 `证据` 都为空 | 「这条标了事实但没给出处：要么补出处，要么改成推断并写明依据」 |
| `INFERENCE_NEEDS_BASIS` | `来源.kind = 推断` 且 `依据` 空 | 「标了推断但没写依据：推断必须写明依据」 |
| `INFERENCE_NEEDS_CONFIDENCE` | 推断缺 `可信度` | 「推断必须给可信度（高/中/低）」 |
| `BAD_CITATION` | 出处不是「材料#工作表#行号」/ 区间不合法 | 「出处要写成 材料#工作表#行号，比如 mat_x#Sheet1#12」 |
| `DANGLING_EDGE` | 边的两端在**写入后**的文档里没有对应节点 | 「这条边指向的节点不存在」 |
| `DUPLICATE_ID` | 正式 id 重复（服务端分配后仍撞） | 内部错误，`write_failed` |
| `TOO_MANY` | 一次批量 > 50（AI 工具入口） | 「一次最多 50 条，请分批」 |
| `NOT_HGRAPH` | 路径后缀（小写归一）不是 `.hgraph` | 「只能改关系图文件（.hgraph）」 |
| `OUTSIDE_PROJECT` / `LINK_ESCAPE` | 真实路径不在项目目录内 | 「路径越出项目目录」 |
| `STALE` | 前端带了 `版本` 且 ≠ 当前 | 「这份图在你打开之后被改过。为避免覆盖别人的改动，请重新载入」 |

## 3. 写（保留与序列化）

1. **未知键保留**：序列化基于 `原文树`——只覆盖已知键，未触碰的键与未知键原样输出；`null` 补丁 = 删该键。
2. **`更新于`** 由服务端写；客户端提供的值忽略。
3. **键顺序**：不保证；不因键顺序变化产生 diff 噪声以外的语义变化（`git diff` 可能显示重排，属可接受）。
4. **编码**：UTF-8，无 BOM；行尾 `\n`；末尾一个换行。
5. **空文件**：`init` 写骨架；读 0 字节 ⇒ 先 `init`。

## 4. 幂等与批次

| 入参 | 语义 |
|---|---|
| `幂等键` | 同键重复调用返回上次结果（含映射与版本），**不重复写**；窗口 10 分钟（进程内） |
| `批次` | 原样回传；前端按它把多步合并成一步撤销 |

## 5. 负向不变量（每条必须有一条用例）

- 通用写口 `PUT /openhive/file/write` 对 `.hgraph` 返回拒绝（`HGRAPH_READONLY`）。
- 全仓 grep `writeFile` / `save` 对 `.hgraph` 的调用点只有 `hgraph-ops`。
- 图文件**不产生任何数据库写入**（SC-008）。
- 解析失败的文件：`hgraph/ops` 与 5 个 AI 工具都拒绝写。
