# Data Model：关系图产物（.hgraph）

> 本文件只描述「图文件里的数据形状」与「从库事件到图节点的映射」；不新增数据库表，不改变既有表结构。

## 1. 顶层结构（不变）

```text
图文件 {
  格式: 1
  标题: string
  创建于: string
  更新于: string
  设置: { 线宽度量, 次数阈值, 金额阈值, 外环阈值 }
  节点: 节点[]
  边: 边[]
  文字: 文字[]
}
```

## 2. 来源（唯一变更点）

```text
来源 {
  kind: "实体" | "关系" | "推断" | "手写" | "事件"    // ← 新增 "事件"
  实体?: string      // 所绑库对象 id（事件复用此槽位 = case_event.id）
  值?: string
  库类型?: string    // 事件 = 事件类型
  可信?: string      // 事件 = trust_state
  关系们?: string[]
  依据?: string
  并入?: string
}
```

**规则**
- `kind="事件"` 时 `来源.实体` MUST 非空；为空 ⇒ `BAD_SHAPE`（不得存半绑定态）。
- `kind="事件"` MUST NOT 要求 `依据`（事件不是推断）。
- `kind="事件"` MUST NOT 与 `kind="实体"` 混用：「已在图上」判定只认 `实体`。
- `kind="手写"` 的事件节点不写 `来源.可信`。

## 3. 节点

```text
节点 {
  id, 名称, 类型, 细类?, 来源: 来源, 可信度?, 属性?: 属性[],
  出处?: 出处[], 时间: {首, 末}, 备注?, x, y,
  外环?: {档?, 颜色?}, 出现序?, 链接?, 锁定?, 样式?
}
```

**事件节点的落点**

| 九格 | 字段 | 说明 |
|---|---|---|
| 干什么 | `名称` + `类型` | 名称 = 摘要；类型取事件类型词表（既有 `事件类型们`） |
| 何时 | `时间.首` / `时间.末` + 属性 `时间精度` | 精度取值：`日` / `时` / `分`；未标按 `分` 展示 |
| 谁 / 和谁 / 何地 | `参与方·<角色>` 或角色边 | 已对上档案 ⇒ 节点 + 角色边；未对上 ⇒ 属性原文 |
| 多少钱 | 属性 `金额` | 数字+单位连写，单位必填 |
| 其他 | `属性[]` 其余键 | 原键保留 |
| 出处 | `出处[]` | `fact_type='event'` |
| 可信度 | `来源.可信` + 徽标 | 手写不写，徽标恒「手写」 |
| 事件间关系 | `边` 标签 `先` / `同时` / `同一事件` | 本轮只手写，不从库取 |

**保留属性键**（写进格式契约，语义固定）
- `金额`：`<数字><单位>`（如 `12000元`）。
- `时间精度`：`日` | `时` | `分`。
- `参与方·<角色>`：角色取自 `case-card-template.ts` 的角色词表，值 = 原文（如 `李*四`）。

**必填与兜底**
- 必填：`id/名称/类型/来源/x/y/时间`。
- `名称` 为空 ⇒ 落盘前兜底为「`类型` · `金额|时长` · `时间`」。
- `时间` 为空 ⇒ **拒绝落盘**（事件节点）。

## 4. 边（事件相关语义）

| 从 → 到 | 线型 | 标签 | 性质 | 依据 |
|---|---|---|---|---|
| 事件 → 参与方 | 实线 1px + 箭头 | 角色（付款方/收款方/…） | `推断` | 手写：`手写事件「<摘要>」的<角色>`；库：`库事件 <event_id> 的<角色>` |
| 事件 → 事件 | 点线 + 箭头 | `先` / `同时` / `同一事件` | `推断` | 同上口径 |
| 实体 → 实体 | 不变 | 关系名 | 既有 | 既有 |

**硬闸（照抄既有，不新增）**：推断边 `依据` + `可信度` 非空；事实边 `出处` 或 `证据` 非空。

## 5. 状态机：手写 ↔ 绑定

```text
[手写事件] --绑定(加入库事件)--> [绑定事件]
[手写事件] --删除--> (无)
[绑定事件] --删除--> (无)
[绑定事件] --解绑--> 不存在（不提供）
```

- 手写态：九格可编辑；无可信态控件；徽标「手写」。
- 绑定态：九格只读；仅 `备注` 与 `外环` 可改；徽标「库事件」。
- 态只在「绑定/加入」动作里变化；输入过程中不切态。

## 6. 校验规则汇总（写盘前）

| 规则 | 触发 | 结果 |
|---|---|---|
| 来源类别合法 | `来源.kind` 不在五值内 | 拒写（既有） |
| 事件绑定完整 | `kind="事件"` 且 `来源.实体` 为空 | `BAD_SHAPE` |
| 必填字段 | 缺 `id/名称/类型/来源/x/y/时间` | 拒写（既有） |
| 出处硬闸 | 绑定事件 `出处` 为空 | 拒绝上图 + 提示 |
| 推断边依据 | `性质="推断"` 且缺 `依据`/`可信度` | 拒写（既有） |
| 事实边证据 | `性质="事实"` 且 `出处`/`证据` 皆空 | 拒写（既有） |
| 档位范围 | `外环.档` / `线宽档` 不在 0–4 且非自动 | 就地提示、**不写盘** |
| 外环颜色 | 不在 7 预设 + 自动 | 下拉约束，不接受自由文本 |

## 7. 兼容性

- 旧图文件（无 `kind="事件"`）继续可读、可写，行为不变。
- 新图文件在旧客户端：不承诺可读（格式版本仍为 1；`来源类别们` 变宽会让旧客户端报类别非法——按「不要求旧客户端读新文件」处理）。
- 不新增数据库表；事件、参与方、出处全部经既有读出口消费。

## 8. 规模与性能假设

- 单图节点量级沿用现状（数百节点可交互）。
- 强度过滤为 O(E) 过滤；事件映射为 O(参与方数)；均无全量重算。
- 无新增性能承诺；不引入缓存层。
