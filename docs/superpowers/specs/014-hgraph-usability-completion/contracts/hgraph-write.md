# 契约：关系图写接口（客户端 ↔ 服务端）

## 请求体（不变，字段语义收紧）

```text
POST 写图 {
  路径: string
  版本: string          // CAS 基线版本
  操作: 操作[]
  批次?: string         // 一次用户动作 = 一个批次
  幂等键?: string       // 本次新增使用（服务端已支持，无需改动）
}
```

## 幂等键语义（本次明确）

1. 客户端生成：`web:<图路径>:<实例段>:<递增序号>`，实例段 = `时间戳36进制-实例计数-随机8位`（每个编辑器实例生成一次，页面内不变）。**实例段不可省**：服务端只按键查表、不校验载荷，若序号空间跨页面实例复用，刷新后的不同载荷会命中旧键而被重放（US1 评审 C1）。
2. **复用条件**：重试的请求体与上次失败请求体**逐字相同**（同版本、同操作序列）。
3. 载荷任何一处变化 ⇒ 生成新键（否则服务端重放旧结果，新改动被静默丢弃）。
4. 同键重放：服务端返回上次结果，`重放: true`，节点/边数量不变。

### `批次` 不是幂等键

`批次 = 批-<序号>` 每次发送都自增（`editor.tsx:854`），而「重试」正是新的一次发送 ⇒ 同一个失败载荷重试两次会带两个不同 `批次`。**幂等键必须独立生成**，与 `批次` 分属两个字段。

服务端窗口为**进程内 10 分钟**（`hgraph-ops.ts:350`），按「人 ＋ 项目 ＋ 归一路径 ＋ 键」隔离（`:366-371`）；窗口外同键不再重放，退化为普通写入。`写结果.重放` 已回传，客户端当前未消费（`hgraph-api.ts:85-88`），本契约要求客户端**不因 `重放: true` 改变成功处理**（成功就是成功）。

## 冲突与超时处理

| 场景 | 客户端行为 |
|---|---|
| 请求超时（未收到应答） | 先读一次盘；盘上内容 == 「已存文档 + 本批」⇒ 静默采纳版本、不提示；否则按冲突提示 |
| 收到 `VERSION_CONFLICT` | 同上先读盘再判定，不直接报「被改过」 |
| 换 id 后出现重复 id | 立即整图重载，提示「图和你本地不一致，请重新载入」 |

## 同名复用开关

- 请求体**不新增字段**；开关是服务端函数入参（`应用操作(文档, 操作, { 同名复用 })`），由调用方决定：
  - AI 工具 `graph_add` ⇒ `true`
  - Web 编辑器、复制/粘贴、Alt+拖 ⇒ `false`（缺省）
- 开关只影响「名称+类型相同且无显式 id」的加节点分支；其余操作不变。

## 不变式

- 一次请求 = 一次原子写、一个版本推进。
- 一次用户动作 = 一个批次 = 一次撤销。
- 写入前的来源闸与必填校验顺序不变（先校验后写）。
