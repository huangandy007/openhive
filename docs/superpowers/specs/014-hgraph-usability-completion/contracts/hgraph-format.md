# 契约：.hgraph 图文件格式

## 版本

`格式: 1`（不变）。本次为**加法式**扩展：新增一个来源类别取值与三个保留属性键。

## 来源类别（`来源.kind`）

| 取值 | 含义 | 必须携带 |
|---|---|---|
| `实体` | 绑定库实体 | `来源.实体` |
| `关系` | 绑定库关系 | `来源.实体`（关系 id） |
| `推断` | 推断产生 | `依据` + `可信度` |
| `手写` | 手工创建 | — |
| `事件` | **新增**，绑定库事件 | `来源.实体`（事件 id）+ 出处非空 |

## 新增校验

1. `kind="事件"` 且 `来源.实体` 缺失/空串 ⇒ 错误码 `BAD_SHAPE`，错误文案指明「事件必须绑定库事件 id」。
2. 事件节点 `时间` 缺失 ⇒ 拒写。
3. 事件节点 `名称` 为空 ⇒ 落盘前兜底（不报错）：`<类型> · <金额或时长> · <时间>`。

## 保留属性键（`属性[]` 内，语义固定）

| 键 | 值形态 | 用途 |
|---|---|---|
| `金额` | `<数字><单位>`，如 `12000元` | 事件卡第一行、面板「多少钱」 |
| `时间精度` | `日` \| `时` \| `分` | 事件卡第二行渲染、面板「何时」 |
| `参与方·<角色>` | 原文，如 `李*四` | 未对上档案的参与方 |

其余属性键的含义不变，一律归入九格的「其他」。

## 兼容

- 读：旧文件（无 `事件`）行为不变。
- 写：旧文件被新一轮编辑后可能出现 `事件` 节点；不做迁移、不批量改写既有文件。
- 不要求旧版客户端能读含 `事件` 的新文件。
