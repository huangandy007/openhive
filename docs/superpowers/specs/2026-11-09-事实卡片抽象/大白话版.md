# 事实卡片抽象 · 大白话版

> 这一版不用术语，给不懂技术的人看。
> 详细论证与文献依据见同目录 `讨论记录.md`。

---

## 一、现在的问题

我们原来的想法是：不管什么数据，都把它的字段塞进同一张表。

结果发现塞不完。资金要「对手账号、对手户名、本方账号、方向」，话单要「主叫、被叫、时长」，订餐又要「商家、收货人、电话、地址」……**每来一种新数据，表就要加一列**。你说了，还有住宿、火车、飞机、扫码——根本列不完。

**这条路走不通。**

---

## 二、换个想法：把数据分成两层

### 第一层：账本

一份文件进来，一行一行照抄，一个字不改。

它的任务只有一个：**将来能拿给法官看，这句话出自哪份文件、第几页、第几行。**

这一层永远不再加列。

### 第二层：卡片

把账本里每一行，翻译成一张统一格式的卡片：

```
什么时候   2024-11-08 22:10 入住 → 次日 08:30 退房
谁         张三（身份证 420...，是入住的人）
在哪       XX宾馆（XX路88号）
干了什么   住宿
和谁       李四（同住）
多少钱     380 元
其他       房间号 305
出处       第 7 份文件 · Sheet1 · 第 27 行｜原文："22:10 入住 305"
可信度     自动抽取
```

住宿、话单、资金、订餐、乘车——**最后都长成一个样。**

---

## 三、为什么这样就能查了

你说的那些场景，剥掉外壳全是四个字：**谁、何时、何地、干了什么。**

- 案发时到过现场 → 同一时间、同一地点、有这个人
- 现场周边住过 → 同一地点附近、案发前后、有这个人
- 同时入住 → 同一时间、同一地点、还有别人
- 给谁转了账 → 同一时间、这两个人、一笔钱
- 作案前打了电话 → 同一时间、这两个人、一通电话

**来源无穷，问题有限。** 卡片就是把这几个问题固定下来。

---

## 四、卡片上"谁"要写什么

不能只写"张三"，也不能只写一个编号。要三样都写：

```
编号（系统给的档案号） + 身份（是入住的人，还是被转账的人） + 原文（"张三"两个字）
```

- 只有名字 → 换个文件又写"张三"，不知道是不是同一个人
- 只有编号 → 翻不回原文，法官不认
- **编号用来查，原文字用来信**

---

## 五、认人有两个讲究

**第一，有先后。**
身份证最可靠，手机号次之，银行账号再次，姓名最不可靠（重名太多）。顺序不能乱。

**第二，要看时间。**
一个手机号，2019 年是张三用，2022 年给李四了。只看"号码一样"就会把两个人当成一个——这是最要命的错误。

**地点也一样**：宾馆写全称还是简称，得能认出是同一个地方。

---

## 六、以前的"实体"开发没白做

之前做的实体表、关系表、关系图、实体档案页，**正好就是这套东西要用的**。它们是"档案"和"关系网"。

问题只有一个：**它现在只接了文字材料（笔录、报告），没接表格。**

```
文字材料 ──► 实体 / 关系 / 事件 ──► 图谱 / 档案   ✅ 通
表格明细 ──► 只有一行行原始数据              ✂️ 断在这里
```

所以要做的是**把断掉的地方接上**，不是推倒重来。

---

## 七、查了论文，结论是：方向对，还漏了三件事

我们这套做法，学名叫「事件中心知识图谱」，论文里早有定论：

- **事件和实体是两类节点**，靠"谁参与了这件事、扮演什么角色"连起来。我们画的九格，跟论文里的「who / when / where / what」一一对应。
- 出处（这条结论从哪来）是**独立的一层**，不能混在事件里。这一点国际上有标准（W3C PROV）。

但有三件事我们没想到：

1. **同一件事会在多份材料里重复出现。**
   住宿单说一次，笔录又说一次——这是同一件事，不是两件。得有办法认出来，不然统计会翻倍。

2. **卡片会有"空格"，而且得说清空格是原文没有、还是我们猜的。**
   比如住宿单没写退房时间。论文的做法是给每条信息打标记：原文抄的 / 推出来的 / 模型生成的。

3. **事件和事件之间也有关系。**
   "先入住、后转账"、"案发前打了电话"——这是事与事之间的前后顺序，我们现在只做了"事和人"的关系。

还有一条最要紧的：**出处不能让 AI 说，必须由系统自己记。** 研究显示，大模型编造引用时，连拿另一个大模型去核对都查不出来。所以"哪份文件第几行"必须由程序绑定，AI 碰不到。

---

## 八、还没定的五件事

1. **"同一个地方"按什么算**——同一个宾馆？同一条街？周边几公里？这直接决定"现场周边住过"查得准不准。
2. **一条记录算几张卡片**——住宿的"入住"和"退房"是一张卡片的两头，还是两张？
3. **怎么判断两张卡片是同一件事**——同一份文件里的重复，和不同文件里的同一件事，判法不一样。
4. **事件之间做到哪一步**——建议先只做"谁先谁后"，"因为所以"不做（靠猜，最容易错）。
5. **认人的具体规则**——没有身份证怎么办、一个号码换过主人怎么拆。
