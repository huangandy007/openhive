## 6. 缺口表（照实写，不许写成「已覆盖」）

### 6.1 本刀明示缺口（brief 指定 8 条）

1. **旧材料没有 `mapping.工作表[].列`** ⇒ 预览 409 `material_not_ready`，需重新解析。已由 routes 用例 `旧材料缺 mapping.工作表[].列 ⇒ 409 material_not_ready` 钉住（是行为，不是缺陷）。
2. **预览的 `提及` 用归一化值兜底**：明细表没有原文旁路列，预览卡与 ingest 落库卡的 `提及` 来源不同；spec §13.3 的逐项等价比较**未覆盖**（见 6.2）。
3. **无模板版本历史 / 回滚**；`case_event.template_id` 不随版本变，单卡追溯不到映射版本（只能追到模板行 id）。
4. **模板卡不产关系 / 别名 / 实体属性**；卡片用途恒「未分类」（`用途.一级 === "未分类"`，模板卡不跑用途判定）。
5. **不支持多行合成一张卡**（住宿式区间合并仍在资金/话单专用通路里，模板引擎不做区间合并）。
6. **没有「申请新事件类型」入口**（事件类型只能从词表选）。
7. **MCP 写工具（建 / 改模板）未提供**，只有 HTTP 六口。
8. **真栈 A14 未跑**：未获用户同意重启，不启动、不停止、不探测真栈进程（见第 7 节）。

### 6.2 本次新增登记（测试 / 范围 / 设计偏差）

1. **`money_flow` 的单笔最大与计数不按模板可见条件过滤**（`case-mcp-tools.ts:2236/2252`，函数 `:2124`）。范围外已登记缺口；设计 §11.2 把 `money_flow` 写成「读关系表」与代码不符（设计偏差 1）。
