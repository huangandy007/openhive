# 卡片模板编辑器（第二刀：前端）设计

> 日期：2026-11-14
> 范围：SolidJS 前端编辑器 + 内核两个只读/恢复小口（词表、恢复）。内核主体（迁移 0044、校验、DAO、通用翻译引擎、ingest 接线、HTTP 六口、AI 默认过滤）见 `2026-11-14-P4-卡片模板-内核-design.md`（下称「内核设计」）。
> 依据：`01-事实卡片与数据翻译-设计.md` §4.7（模板怎么做、怎么配、四类不可配、两个防错设计）；内核设计 §10（HTTP 契约）、§11（AI 可见性）、§14.1（A14 分期）；`openhive-DESIGN.md` §4（组件与布局）。

## 0. 已确定的八个决策（本轮 brainstorm 逐条认可）

| # | 决策 | 理由 |
|---|---|---|
| D1 | **独立管理页先行**：案件里新增「卡片模板」视图，解析流程内引导留二期 | 流程内引导要改解析向导，面大；A14 不要求 |
| D2 | 入口放**材料抽取视图顶部工具条** | 模板就是给材料表格用的，语义最近 |
| D3 | 列表**分「我的模板 / 内置模板」两组**，内置只读；停用默认折叠 | 民警看得到系统已有什么，又不会点坏 |
| D4 | 预览材料在**编辑器内选**（默认最近一份已解析材料） | 语义清楚；无材料时给明确空态 |
| D5 | **多参与者 + 多属性**：「和谁」「何地」可多行、「其他」可多键（地点角色的多行落「何地」，见 §5.3 R1） | 内核本来就支持数组/映射；火车/航班需要两个地点角色 |
| D6 | **新增词表口**（内核第 7 口）：下拉选项全部服务端出 | 避免字段/角色/槽规则在前端再实现一遍（`#002-06`） |
| D7 | **新增恢复口**（内核第 8 口）：停用可恢复 | 内核错误文案本就写「需先恢复」，没有口就是空话 |
| D8 | 开发完成后交付**使用说明**文档（含截图位） | 用户明确要求 |

## 1. 范围

### 1.1 做什么

1. 新中栏视图 `case://<projectId>/templates/all`（列表 + 抽屉编辑器）。
2. 材料抽取视图顶部「卡片模板」按钮，打开该视图。
3. 模板生命周期 UI：新建 / 修改 / 预览 / 转正 / 停用 / 恢复。
4. 内核新增两口：`GET card-template/vocab`、`POST card-template/restore`。

### 1.2 明确不做（第一版）

解析流程内引导、模板复制/另存、版本历史与回滚、批量操作、内置模板编辑、AI 生成模板、MCP 写工具、多行合成一张卡、新事件类型申请。

## 2. 信息架构与路由

### 2.1 视图接入

案件界面没有 URL 路由，视图是 `case://` 伪路径 + 中栏 tab（`packages/app/src/center/case-route.ts`）。接入点三处：

| 文件 | 改动 |
|---|---|
| `center/case-route.ts` | `视图表` 加 `"templates"`（类型自动派生，解析器按表判成员） |
| `center/case-view.tsx` | `switch` 加 `case "templates"`（穷尽检查强制；读 context 的约束不变，仍在 `CaseView` 外层） |
| `center/case-views/material-facts.tsx` | 顶部工具条加「卡片模板」按钮，用 `useCenterTabs()` 打开 `案件伪路径({ projectId, view: "templates", arg: "all" })`，标题「卡片模板」 |

`arg` 固定 `"all"`，与 `alerts` 同款约定（`case-alerts-api.ts:62`）。

### 2.2 页面结构

```
┌ 卡片模板 ──────────────────────────────── [ + 新建模板 ] ┐
│ 我的模板                                                  │
│  · 通话  通话  [已验证]  命中 12     编辑 · 预览 · 停用    │
│  · 订餐  订餐  [未验证]  命中 0      编辑 · 预览 · 转正 · 停用 │
│ 内置模板（只读）                                           │
│  · 资金  资金交易  [内置]            查看                  │
│ ▸ 已停用的模板（2）· 点击展开         每行：编辑 · 预览 · 恢复 │
└───────────────────────────────────────────────────────────┘
         └── 右侧 480px 抽屉：新建 / 修改 / 预览 / 转正确认 ──┘
```

> **2026-11-14 订正（最终广审 I-2）：已停用行实际落地为「预览 · 恢复」，不是「编辑 · 预览 · 恢复」。**
> 停用行点「预览」打开的是**只读抽屉**（可预览、不可保存）：标题「查看已停用的模板」，
> 内文「模板已停用：先恢复才能修改」。内核 `改模板` 对 `disabled_at !== null` 一律回 `not_found`，
> 可编辑抽屉会让民警「编辑一个不存在的模板」；要修改须先恢复。

- 状态派生（单一函数）：`disabled_at ≠ null` ⇒ 已停用；否则 `verified_at ≠ null` ⇒ 已验证；否则 未验证。
- 状态徽标**文字 + 颜色**双通道（`openhive-DESIGN.md` §4.3：不只靠颜色）。
- 内置模板（`内置:` 前缀）只读：无编辑/停用/转正/恢复按钮，仅「查看」打开只读抽屉。

## 3. 词表口契约（内核第 7 口）

**路由**：`GET /openhive/case/card-template/vocab`
**鉴权**：已登录即可（401 无登录）；**不收 projectId**——词表是代码常量，不含案件数据。

**响应**（中文键，与既有 HTTP 契约一致）：

```jsonc
{
  "槽们": ["谁", "和谁", "何时", "何时止", "何地", "多少钱", "其他"],
  "事件类型们": [
    { "值": "通话", "可选": true },
    { "值": "资金交易", "可选": false, "原因": "资金交易由方向算法负责、住宿由区间合并负责，不能建用户模板" },
    { "值": "住宿", "可选": false, "原因": "资金交易由方向算法负责、住宿由区间合并负责，不能建用户模板" }
  ],
  "字段们": [{ "值": "caller", "显示名": "主叫号码", "种类": "号码" }],
  "槽可选字段们": {
    "谁": ["caller", "callee", "personName", "..."],
    "和谁": ["caller", "callee", "merchant", "..."],
    "何时": ["startedAt"],
    "何时止": ["startedAt"],
    "何地": ["address"],
    "多少钱": ["amount"],
    "其他": ["durationSec", "balance", "..."]
  },
  "其他不可选种类": ["金额", "时间", "方向"],
  "角色们": [{ "值": "主叫", "地点类": false }],
  "默认角色": { "谁": "主体", "和谁": "对方", "何地": "地点" },
  "实体类型们": ["人", "账户", "号码", "..."],
  "必填恒含": "谁"
}
```

**生成规则（零新判据，全部从现有常量派生）**：

- `槽们` ← `九格们`；`角色们` ← `角色们`（16 个），`地点类` = `地点角色们` 成员；`默认角色` ← `默认角色`；`实体类型们` ← `case-extract` 的 `实体类型们`；`必填恒含` ← 常量 `"谁"`。
- `事件类型们` ← `事件类型们`（9 个）；`资金交易` / `住宿` 标 `可选: false`，`原因` 取 `检查模板定义` 同一条文案（`case-card-template.ts:416-417`）。
- `字段们` ← `字段目录` + `字段显示名`（17 个字段）。
- `槽可选字段们`：前六槽 = 字段中 `槽允许种类[槽]` 含该字段种类者；`其他` = 字段中种类不属于 `其他拒收种类` 者。与 `检查模板定义` 同一份规则，不另写判断。
- `其他不可选种类` ← `其他拒收种类`（反向规则原样暴露）。

**为什么不让前端自己过滤**：`字段种类 × 槽允许种类` 的映射只该有一处（`#002-06`）；前端拿到数组直接渲染。

**前端缓存**：模块级缓存一次（词表是代码常量）；页面刷新即换代。内核升级词表后，已打开的页面需刷新——登记为缺口，不做轮询。

## 4. 恢复口契约（内核第 8 口）

**路由**：`POST /openhive/case/card-template/restore`
**body**：`{ "projectId": "…", "id": "用户:…" }`
**权限**：项目**属主**（与建/改/停用/转正同档）。

| 情形 | 响应 |
|---|---|
| 成功恢复（`disabled_at` 置 null） | `200 { "ok": true }` |
| 已启用（幂等） | `200 { "ok": true }` |
| 内置模板 | `409 { error, code: "immutable" }` |
| 同事件类型已有启用中的用户模板 | `409 { error: "同类型下已有启用中的用户模板；请先停用旧模板再恢复", code: "conflict" }` |
| 不存在 | `404 not_found` |
| 非属主 | `403`（文案「只有项目属主能维护卡片模板」） |
| 未登录 | `401` |

**实现**：DAO 加 `恢复模板`，与 `转正模板` 同款（条件 `UPDATE … set disabled_at = null where project_id = ? and id = ? and disabled_at is not null`；0 行后回读区分 已启用 / 不存在 / 内置；唯一索引冲突翻 `conflict`）。路由只翻错误码。

## 5. 编辑器交互

### 5.1 打开与关闭

- 右侧 480px 抽屉（Kobalte Dialog，照 `governance/overlay.tsx` 的形态；**不重构 governance**，新组件自带同款最小实现）。
- 新建与修改同一组件；修改时载入现有定义。
- 有未保存改动时点「取消」或关闭 → 二次确认；无改动直接关。

### 5.2 默认值

- 事件类型**默认空**（必须显式选）；`可选: false` 的选项置灰并给 `原因`。
- 角色默认取 `默认角色`；实体类型默认「不指定」（可选）。
- **「谁」恒必填**：勾选锁定不可取消（内核 `解析必填` 恒含「谁」）；其余槽可自由勾。

### 5.3 槽位控件

| 槽 | 控件 | 选项来源 |
|---|---|---|
| 谁 | 字段 + 角色 + 实体类型 | `槽可选字段们.谁` |
| 和谁 | 0..n 行（字段 + 角色 + 实体类型），行可删 | `槽可选字段们.和谁` |
| 何时 / 何时止 | 字段下拉，空 =「无」 | `槽可选字段们.何时` / `.何时止` |
| 何地 | 0..n 行（字段 + 地点角色：地点/出发地/到达地），行可删 | `槽可选字段们.何地` + `角色们`（`地点类: true`） |
| 多少钱 | 字段下拉 | `槽可选字段们.多少钱` |
| 其他 | 0..n 行，只有字段（不收角色/实体类型），行显示「显示名 + 落点」 | `槽可选字段们.其他` |

> **2026-11-14 计划期更正（R1：「何地」按 0..n 行实现，不是单值下拉）**。内核 `单值槽` 只有
> 谁/何时/何时止/多少钱（`case-card-template.ts:400`）；`何地` 不限条数，角色限地点类，引擎逐条产出
> 并强制实体类型「地点」（`case-template-translate.ts:182-186`）。今天字段词表里只有 `address` 一个
> 地点字段，且同一字段不能在模板里出现两次（`检查模板定义`），所以**实际最多一行**——控件与「和谁」
> 共用同一个行组件，不多写特例；将来词表加第二个地点字段（出发站/到达站）时编辑器不用改就能表达。
> 地点角色**不能**写进「和谁」（`校验角色与实体` 只收人称角色），所以初稿火车示例里「和谁 = 出发地」
> 不成立：双地点是字段词表的缺口，不是本刀的。

### 5.4 即时校验（未通过 ⇒ 保存置灰 + 行内提示）

- 名称为空；事件类型未选；「谁」的字段未选。
- 所选字段不在该槽可选集（修改旧模板 / 词表变更时才会出现）。

### 5.5 服务端错误一律原样展示中文串

| code / 状态 | 展示与动作 |
|---|---|
| `400 bad_request` | 顶部错误条展示 `error`（多条以「；」连接），不二次包装 |
| `409 conflict`（新建/修改时） | 「同类型下已有启用中的用户模板…」+「去停用旧模板」按钮（关抽屉、定位列表） |
| `409 state_changed`（转正） | 「模板在预览期间被修改，请重新预览」；预览按钮高亮 |
| `404 not_found` | 提示模板已被删或停用，刷新列表 |
| `409 immutable` | 「内置模板由代码规则维护…」（正常应被 UI 挡住，兜底） |
| `403` | 「只有项目属主能维护卡片模板」——按钮不做隐藏（列表口不返回属主身份，隐藏无从判断） |

### 5.6 修改已验证模板的后果必须明说

内核 `update` 只在 `slots` / `required` / `event_type` 真变时清空 `verified_at`（**只改 `name` 不重置**，2026-11-14 真栈 A14-5 实测）。修改已验证模板时，抽屉顶部常驻提示：**「改「哪一列对应哪一项」「事件类型」或「必须填满才产卡片」再保存，会回到未验证，需重新预览并转正；只改名称不影响」**；改了内容并保存成功后行状态立即变「未验证」。

## 6. 预览、转正、停用、恢复

### 6.1 预览（抽屉内，只读、不落库）

- 材料下拉：列出本项目已解析材料，默认最近一份；无材料 ⇒ 按钮禁用 +「先导入并解析材料」。
- 请求：`POST card-template/preview`，body 二选一——编辑中的**草稿** `{ projectId, materialId, template }`（`template` 为 `{ name, eventType, slots, required }`），或已保存模板 `templateId`。**编辑器中一律传草稿**，不需要先保存。
- 响应（内核设计 §10.3）：`{ 卡片数, 跳过: {原因: 数}, 卡片们, 工作表们: [{sheet, 卡片数, 跳过}] }`。
- 展示：汇总条（卡片数 / 跳过数 + 原因明细）→ 按工作表回执 → 卡片表（摘要 / 时间 / 参与者角色 / 来源 `sheet#rowNo` / 金额）。每表最多前 20 行，多表时卡片数可能 > 20。
- `409 material_not_ready`：原样提示「这份材料还没有可预览的解析结果（旧材料需要重新解析）」。
- 编辑任何字段后结果区置灰 +「需重新预览」，转正按钮同时禁用直到重新预览成功。

### 6.2 转正（只对已保存的未验证用户模板）

- 草稿不能转正：内核 `verify` 用库里的模板行重跑预览，所以流程固定为 保存（未验证）→ 列表/抽屉「转正」→ 确认框。
- 确认框：再选「用哪份材料复核」（默认最近一份）+ 文案「转正后，这个模板产出的卡片才会进入 AI 的默认查询范围；现有卡片不会被改」。
- 请求：`POST card-template/verify`，body `{ projectId, id, materialId, expectedVersion? }`。
- 结果映射：

| 结果 | 界面 |
|---|---|
| 成功 | 行状态变「已验证」，显示 `verified_at` |
| `400 preview_failed` | 展示 `error` + `跳过` 原因表，留在未验证 |
| `409 state_changed` | 提示刷新重试 |
| `already: true` | 「已是验证状态」 |

### 6.3 停用

二次确认：「停用后：该模板不再参与自动选模板；已产出的卡片保留可追溯。可随时恢复。」（恢复口落地后此句成立。）

### 6.4 恢复

「已停用」区行内「恢复」→ 二次确认 → `POST card-template/restore`。`409 conflict` 展示内核原文 +「去停用旧模板」。恢复后行回到「我的模板」并保持原 `verified_at` 状态（恢复不改验证状态）。

## 8. 测试与门禁

### 8.1 内核测试（扩 `packages/opencode/test/server/openhive-case-card-template-routes.test.ts`）

- **词表同源双向**：`槽可选字段们` 每个字段 + 对应槽 ⇒ `检查模板定义` 通过；每槽各取一个表外字段 ⇒ 被拒。`其他不可选种类` 三类逐一被拒，`时长`/`余额` 放行。
- **恢复口五态**：停用→恢复→列表可见；同类型已有启用中 → 409 `conflict`；内置 → 409 `immutable`；非属主 → 403；未登录 → 401。恢复不改 `verified_at`。
- 变异：删掉恢复的 `and disabled_at is not null`、把冲突检查去掉 → 对应用例必须红。

### 8.2 前端组件测试（`packages/app/src/**/*.test.tsx`，happy-dom + testing-library）

- 列表：分组正确、内置无操作按钮、停用折叠、状态派生。
- 编辑器：默认角色、谁锁定必填、槽下拉只含词表口字段、表外值选不到、错误条原样展示。
