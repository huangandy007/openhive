# 前端落地策略：opencode 原生换皮 + 新增三功能

- **日期**：2026-08-30
- **状态**：待审阅
- **主题**：openhive 前端不走「React 自研」，而是复用 opencode 原生前端（SolidJS），做品牌换皮 + 补齐三个多租户缺失功能
- **关联**：本文件是对 `2026-08-17-openhive-design-v1.md` 前端部分（§7/§8/§9/§10）的**落地策略修正**——原文档隐含「Figma 导出 React 前端即最终前端」，本文件推翻该假设

---

## 1. 背景与结论

Figma 已产出前端蓝图（`D:\project\study\openhive\front`，React 19 + Vite）。但经过对 opencode 原生前端源码的逐项比对，得出一个关键结论：

> **Figma 蓝图里约 70% 的功能，是在「重新画 opencode 已经有的东西」**（右栏会话、文件树、代码编辑器、模型选择器、Effort、设置面板、会话管理、通知、全屏……）。这些 opencode 原生做得更全、更好，且是 SolidJS——与 Figma 的 React 是两套互不相容的框架。

**因此前端落地策略定为：复用 opencode 原生前端（SolidJS），做「品牌换皮」+「补齐三个多租户缺失功能」，而不是把 Figma 蓝图逐功能重做一遍。**

这与用户在 brainstorming 中「复用 opencode 会话页面 = 改造小」的直觉一致，且范围更大：不止会话，文件树/编辑器/设置/模型选择器**全部复用**。

**Figma 蓝图的新定位**：不再是「要部署的前端」，而是「视觉风格参考 + 交互规范蓝本」——定义 OpenHive 长什么样（浅色专业风、蜂巢品牌、脱敏开关、表格样式等），实现时用 opencode 原生组件去对齐这些视觉。

---

## 2. 关键前提：技术栈不兼容

| | Figma 前端 | opencode 原生前端 |
|---|---|---|
| 框架 | React 19 | SolidJS |
| UI 库 | Tailwind CSS v4 + lucide-react | `@opencode-ai/ui` + `@kobalte/core` |
| 会话 UI | 手绘 `RightAIChat.tsx` | `@opencode-ai/session-ui` 包（60+ 组件） |

- Solid 组件**无法嵌入 React 组件树**，反之亦然。二者只能选其一。
- 选了 opencode 原生，就等于继承了它的会话流、文件树、编辑器、模型/权限/通知等一整套前后端状态系统——这些是自研要花数月重写的东西。

## 4. 三个必须新增的功能

### 4.1 管理员后台（用户管理）

- opencode 无多用户、无账号管理页面，这块**从零建**。
- 前端：一个 admin 页面（用户列表 / 录入 8 字段 / 重置密码 / 停用启用 / 脱敏开关），对应设计文档 §4.2。
- 后端：Auth 服务的用户表 + CRUD API（设计文档 §4.1 已定义 8 字段）。
- 注意：真正的工程量在**后端 Auth 服务**，前端 admin 页只是展示层。

### 4.2 MinIO 备份面板

- opencode 源码**无任何 minio/S3 依赖**，需从零开发前端面板 + 后端存储对接。
- 对应设计文档 §10：工作目录 ↔ MinIO 双向备份/拉回，bucket 按 `{userId}/{projectId}/` 组织，闲置项目自动归档。

### 4.3 站内信（富通知）

- opencode 现有 `notification.tsx` 只有「turn-complete / error」两种 AI 事件。
- 需扩展为 Figma 里的三类（系统 / AI / 文件）+ 未读红点 + 下拉面板 + 标记已读。

## 5. 改造清单（按量级排序）

**必须新建（opencode 完全没有）：**
1. 管理员后台 + 用户管理（前端展示 + 后端 Auth，核心是后端）。
2. MinIO 备份面板 + 后端存储。
3. 站内信（把现有通知从 2 种 AI 事件扩到三类 + 面板）。

**小改（opencode 有，但要贴合多租户）：**
4. 登录重定向 + 首次改密弹窗（挂到 Auth 服务）。
5. 品牌换皮（Logo / 名称 / 标题 = OpenHive）。
6. 系统设置加「脱敏规则」「云端备份」Tab。

**零改造（直接用 opencode 原生）：**
右栏会话全链路、文件树、文件操作、会话管理（含归档/分享）、模型选择器、Effort、全屏、代码编辑器、分屏、字号、导出会话。
