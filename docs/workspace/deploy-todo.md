# 部署侧待办（部署文档的雏形）

**这份文件是什么**：代码侧做不了、**只能在部署环境里关上**的事项总目。每条都注明来源任务、
为什么必须由部署侧做、以及**怎么验**。

**为什么单开一份**：多个任务都有「写进部署文档」的待办（002 的密钥长度、003 的身份门网络策略、
003 的 OS 级磁盘配额），而仓库里**此前没有部署清单**（T007 也记过同一处境：仓库无部署文档，
`0700` 权限位没有落点）。条目散在各 feature 的 `tasks.md` 里迟早会丢——那份 tasks 收尾后就冻结了。
**各任务落地时把条目「移」进来，不要抄**：抄两份就是两个真相，早晚漂（`LEARNINGS #002-06`）。
