# 证据索引

> 证据台账：回答「这份证据能不能用、能证明什么」。来源 M 只填 M 编号，路径查材料登记表。
> 证明内容写具体事实，不写罪名认定；待证事实必须取受控类别。

## 受控取值

- 法定种类：物证 / 书证 / 证人证言 / 被害人陈述 / 犯罪嫌疑人供述和辩解 / 鉴定意见 / 勘验检查辨认侦查实验等笔录 / 视听资料电子数据 / 待定
- 待定写法：在「风险标记」列写 `种类待定：<原因>；补正期限 YYYY-MM-DD`
- 待证事实：主体身份 / 主观明知 / 客观行为 / 犯罪数额 / 危害后果 / 共同犯罪地位 / 量刑情节 / 程序事实
- 状态：草稿 / 已确认 / 已排除
