# 法律适用区说明

## 存放规范

1. 只放规范性依据，不放材料、证据、研判结论。
2. 推荐分类（按需自建，初始化不预建子目录）：法律法规 / 司法解释与意见 / 立案追诉标准 / 量刑指导 / 判例 / 内部指引。
3. 文件名：`<类型>-<文号或条文号>-<简称>.md`。
4. 文件头必填：名称、文号、条文、版本、生效日期、来源、效力。
5. 只读；勘误另建说明；不得编造、不得用摘要替代原文；引用必须写条文号。
6. 涉密内部指引按保密规定，不进共享项目。
7. 放了什么，登记到 `00-索引.md`。

## 文件头

```yaml
---
名称: <依据名称>
文号: <文号或「条文」>
条文: <具体条文号>
版本: <版本>
生效日期: <YYYY-MM-DD>
来源: <来源>
效力: <现行有效 / 已修订 / 已废止等>
---
```

## 保密要求

- 涉密内部指引不进共享项目；按密级控制访问范围。
- 不放技侦原始记录；技侦只放审批文号、使用说明与经批准的转化材料，且转化材料放 `材料/04-技术侦查/`。
- 对外汇报与共享视图中，敏感字段按平台保密要求处理；原始数据留在受控目录。

## 本案适用分析

- `90-本案适用分析.md` 不预建；需要时从 `assets/本案适用分析.template.md` 复制。
- 只写「本案哪个事实对应哪条依据」，不替人下罪名结论；是否采用由办案人确认。
