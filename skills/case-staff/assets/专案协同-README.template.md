# 专案协同区说明

## 定位

协同层，不是又一个材料柜：管「谁在做什么、定了什么、落实没有、下一步是什么」。
不重复存放材料、证据、文书；引用一律用编号，不复制内容。

## 子目录与产物

| 目录 | 作用 | 关键产物 |
|---|---|---|
| `00-原始记录/` | 未整理的转写稿、手记、外部来件 | 原文保留；整理后末尾标「已整理：C/T/L/V 编号」 |
| `01-每日动态/` | 每天各岗位的汇报 | `YYYY-MM-DD-每日动态.md` |
| `02-专案会议/` | 会议纪要、议定事项、部署 | `C001-日期-主题.md` |
| `03-任务盯办/` | 任务、责任人、期限、状态、反馈 | `00-任务台账.md` + 按需 `T001-任务简称.md` |
| `04-线索流转/` | 线索发现、来源、核查、转研判 | `00-线索台账.md` + 按需 `L001-线索简称.md` |
| `05-印证核实/` | 研判线索落地结果 | `00-印证台账.md` + 按需 `V001-对象-核实.md` |
| `06-人员与组织/` | P/O 主数据 | `00-人员台账.md` + `01-组织架构.md` |
| `07-抓捕筹备/` | 对象清单、方案、编组、资料发放 | `00-抓捕对象清单.md` 等 |

## 每日动态与会议

- 统一半结构化四段：今日工作 / 发现 / 问题 / 明日计划；缺项只提示，不拒绝录入。
- 会议纪要多一节「议定事项与责任人」。
- 同一天多次汇报追加到同一份日报；不足正式会议的碰头只更新日报与台账，不建会议文件。

## 原始记录

- `00-原始记录/` 只存未整理原文；只追加不改写。
- 手记命名 `YYYY-MM-DD-沟通记录-主题.md`；转写稿与外部文档保留原文件名。
- 整理后只追加「已整理：C003 / T012 / L008」与整理时间，不改正文。

## 闭环

- 新线索有 L 编号；部署有 T 编号；落地核实有 V 记录；确认必须回写主数据。
- 同一信息只落一处，其余引用编号；没有回写的，不算闭环。
- `00-协同台账.md` 由 `scripts/digest.py` 首次运行生成，不手改、不预建。
