# 办案规则（AI 工作合同）

本文件是本项目内所有 AI 会话必须遵守的办案规则；涉及案件操作前先读本文件，再读相关台账。

## 硬边界

1. 台账是唯一源，文档是视图；派生内容只改托管块（`AUTO:BEGIN` 到 `AUTO:END` 之间的自动生成区域），块外人工叙述不覆盖。
2. 材料只读：`材料/` 下原件不改名、不拆批、不复制；材料目录内唯一可写文件是 `材料/00-材料登记表.md`。
3. 文书认定事实只能引用证据 E；研判 A 只用于分析、策略与下一步，不得当作证据。
4. 研判结论只写事实说明了什么，不写罪名认定；是否构成犯罪属于文书与法律适用。
5. 不内置任何法律、司法解释、判例全文；`法律适用/` 只放办案人提供的依据，引用必须写条文号。
6. 已签发、已发放文书与 `*-发放版.md` 一律不改原文；变更只追加到 `变更日志.md`。
7. 不代替指挥员决策、不代替侦查员认定事实、不代替法制员签发法律文书。
8. 不编造姓名、金额、时间、文号、法条；拿不准的写「待确认」，不硬下结论。

## 编号与命名

- 编号前缀：M 材料 / E 证据 / F 待证事实（可选） / A 研判 / L 线索 / V 印证 / T 任务 / C 会议 / P 人员 / O 组织 / D 文书。
- 分配编号 = 同前缀当前最大值 + 1；写入前重读台账，冲突重取；已分配号不回收、不复用。
- 我方新建文件只用半角 `-` 分隔，日期 `YYYY-MM-DD`；禁用词：最终版、最新、修改版、副本、新建、未命名。
- 台账优先、文件按需：能用一行台账说清的，不单独建文件。

## 目录与审批

- 顶层 7 个目录固定，AI 永不新建。
- 二级目录以初始化清单为白名单；新类别落 `99-其他` 并出「目录变更建议」，人批准后才建，并记 `变更日志.md`。
- 三级目录只允许 `P001-姓名/`、`图表/` 与 `材料/06-话单与资金/资金/`、`材料/06-话单与资金/话单/`，且必须有内容落位（后两个由初始化创建）。
- 四级目录只允许 `材料/06-话单与资金/{资金,话单}/<人名>/`：人名取流水户名或话单机主姓名，用纯姓名；
  一份多人落 `多人/`，人名不明落 `待确认/`；归档时创建，不按银行、账号或日期再分层。
- 自动：台账行、日报追加、编号分配、M 登记、索引更新。
- 草稿待确认：新建 A/C/T/L/V 文件、P 目录、E 行。
- 必须人批：新建二级目录、移动/改名/删除已有文件、发放版、任何法律文书。

## 材料与归档

- 新文件统一上传到 `材料/00-待归档/`；归档 = 移动到来源目录，文件名不变，必须走平台移动接口，禁止 shell 移动。
- 资金流水归档到 `材料/06-话单与资金/资金/<户名>/`，话单归档到 `材料/06-话单与资金/话单/<机主姓名>/`；
  不得平铺在 `06-话单与资金` 根下。户名/机主不明落 `待确认/`，一份多人落 `多人/`。
- 每次内勤事务先扫收件箱，为新文件分配 M 编号并登记「待归档」；归档时更新当前路径与状态。
- 无法归类的留 `99-其他/` 标「待归类」，下次再定。
