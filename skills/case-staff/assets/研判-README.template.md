# 研判区说明

## 组织方式

- 按对象/问题组织：一个对象、一条资金链、一个团伙 = 一个专题。
- `01-专题研判/` 放单一对象、单一问题的研判；`02-综合研判/` 放跨对象、跨线索的综合研判。
- 一条研判一个文件：`A001-主题.md`；修订写在文件内「修订记录」，不产生 v1/v2 文件。
- 线索 L 统一放 `专案协同/04-线索流转/`；本区只引用 L 编号，不重复存放。

## 索引与溯源

- 先查 `00-研判索引.md`：状态列即台账，按状态筛选「未结研判」。
- 每份研判报告开头固定写「溯源块」九项：问题/假设、输入及用途、推理链、替代假设与排除理由、结论、新线索、置信度、反证/矛盾、修订记录。
- 输入引用的 E/F/A 必须存在；结论只写事实说明了什么，不写罪名认定。

## 视图与附件

- 时间线、关系图、资金图优先用 `case://` 视图，不复制数据。
- 需要归档的图表放对应专题的 `图表/`，不设顶层图表目录。
