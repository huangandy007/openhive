# 专案内勤

本技能只在**一次会话内、被一句话触发**时工作，不是常驻服务；不做定时提醒，也不接入微信、会议录音或警综。
技能只读写当前 openhive 项目目录内的 Markdown 与文件；确定性操作优先用 Python 3 标准库脚本，没有解释器时按「无脚本步骤」用文件工具逐项落地。

## 何时使用

- 项目还是空的（或只有 `.git/`、`.gitignore`、`.opencode/`、`opencode.json`），人说「建一个案件工作区」→ 走**入口一**。
- 项目已是案件工作区（根目录有 `案件信息.md` 与 `AGENTS.md`），人说「记录今日动态」「归档」「整理原始记录」「校验一下」→ 走**入口二**。
- 会话一开始先读项目根 `AGENTS.md`（办案规则合同），编号、命名、边界以该文件与本技能 references 为准，不依赖对话记忆。

## 入口一：建一个案件工作区

1. 读 `references/初始化.md`。
2. 预检目标目录；失败即零写入并说明原因。
3. 探测解释器：`command -v python3 || command -v python`。找到就运行 `scripts/init_case.py`；找不到按 `references/初始化.md` 的「无脚本步骤」逐项建目录、写模板。
4. 输出创建/保留清单；重复执行必须幂等、不覆盖已有文件。
5. 初始化后读 `AGENTS.md`，再开始任何编号或落账动作。

## 入口二：记录今日动态

1. 读 `references/内勤工作流.md`，按其中的固定顺序处理本次事务。
2. 每次内勤事务先扫 `材料/00-待归档/`，为新文件分配 M 编号并登记为「待归档」。
3. 口述汇报按 `references/内勤工作流.md` 的「口述入账」拆成 E/L/T 建议；会议、碰头、转写稿按「原始记录整理」分流；
   人说「归档」按「归档：材料入来源目录」把资金流水落到 `06-话单与资金/资金/<户名>/`、话单落到 `话单/<机主>/`。
   归档后用 `sync_material_path` 复核材料记录仍指向新路径，回执写明「已入库 / 未入库」。
   归档移动后平台会自动清掉 `材料/00-待归档/` 里被搬空的子目录（有文件或 `.gitkeep` 的保留）。
4. 任何写入台账前先给出「编号 + 一句摘要 + 来源」的入账清单，人确认后再落；推断只能进线索或研判输入。
5. 收尾跑 `scripts/validate_case.py`；需要给指挥员看时跑 `scripts/digest.py`。

## 无脚本步骤索引

没有 Python 解释器时，不假装脚本可用，按下列顺序用文件工具逐项落地并自检（详细清单见 `references/初始化.md` 的「无脚本步骤」）：

1. 预检：确认目标目录只含项目基础项，且不是已有案件工作区。
2. 建目录：按 `references/初始化.md` 的「目录清单」逐个创建，顺序为顶层 → 二级 → 三级。
3. 写台账与规则文件：从 `assets/*.template.md` 复制到目标路径，不改写模板内容。
4. 放占位文件：每个初始化后为空的叶子目录放一个 `.gitkeep`。
5. 自检：对照「完成自检」逐项核对目录与文件集合；不一致就补齐，不报告「已建好」。

## 按需加载的规则文件

| 文件 | 何时读 |
|---|---|
| `references/初始化.md` | 入口一：预检、目录/文件清单、幂等、无脚本步骤 |
| `references/内勤工作流.md` | 入口二：固定顺序、口述入账、原始记录整理、收尾 |
| `references/证据规则.md` | 写/改证据索引、判断法定种类与待证事实、F 清单 |
| `references/研判规则.md` | 写/改研判索引与研判报告、处理 A→L→A |
| `references/命名与编号.md` | 分配编号、起文件名、判断目录能否新建 |
| `references/阶段检查表.md` | 更新阶段看板、法制审核节点、移送前自检 |
| `references/时限参考.md` | 填期限字段、判断逾期、做提醒 |
| `references/法律适用规范.md` | `法律适用/` 的存放、索引与保密要求 |
| `references/专案协同规则.md` | 日报、会议、任务、线索、印证、人员组织、抓捕筹备、原始记录 |

## 硬边界

- 不内置任何法律、司法解释、判例全文；`法律适用/` 只提供存放规范与索引。
- 不代替指挥员决策、不代替侦查员认定事实、不代替法制员签发法律文书。
- 研判结论只写事实说明了什么，不写罪名认定；研判不能当证据使用。
- 已签发/已发放文档与发放版一律不改原文，变更只进 `变更日志.md`。
- 台账是唯一源、文档是视图；派生内容只改托管块，块外人工叙述不覆盖。
- 归档移动只能走平台移动接口，禁止用 shell 移动（shell 不会同步材料路径）。
  平台没有 `move_material` 时停止归档并报告；不得退化成 shell 移动。
- 材料只读：不改名、不拆批、不复制；`材料/` 内唯一可写文件是 `00-材料登记表.md`。
  归档时允许在 `材料/06-话单与资金/{资金,话单}/` 下创建人名为名的目录（只建目录，不建文件），
  文件移动一律走平台移动接口。
