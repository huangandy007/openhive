# 内勤工作流（骨架）

本文件是 SKILL.md「入口二」的展开。本任务是**骨架**：只固定处理顺序与各节职责，
「口述入账」「原始记录整理」两节的详细步骤由后续任务在同一文件内顺序补齐，**不得并行编辑本文件**。

## 入口与固定顺序

每次内勤事务（无论人说「记录今日动态」「归档」「整理原始记录」还是「校验一下」）固定按以下顺序处理：

1. 读项目根 `AGENTS.md`，确认编号、命名与边界。
2. 扫 `材料/00-待归档/`：为新文件分配 M 编号、登记为「待归档」；这是自动档，不需要人确认。
3. 按本次输入性质分流：口述汇报走「口述入账」；会议、碰头、转写稿走「原始记录整理」。
4. 先出「编号 + 一句摘要 + 来源」的入账建议与受影响文档，人确认后才写台账。
5. 收尾按「收尾：校验与看板」执行校验；需要指挥员视图时再生成协同台账。

硬性约束：

- 推断只能记为线索或研判输入，不得写成已证实事实。
- 编号取同前缀当前最大值 +1；写入前重读台账，冲突重取。
- 人未确认前，不改台账、不新建 A/C/T/L/V 文件。

## 收尾：校验与看板

每次内勤会话结束前：

1. 运行 `scripts/validate_case.py --root <项目根>`；有错误先报告，不擅自改主数据。
2. 需要给指挥员看时运行 `scripts/digest.py`，生成 `专案协同/00-协同台账.md`；该过程只读台账、不写主数据。
3. 向人报告：本次入账了什么、影响了哪些文档、还剩哪些待确认/待决策事项。
4. 未解决项写清「待确认」，不猜、不硬塞进某个台账。
