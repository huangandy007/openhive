# 命名与编号

## 编号系统

| 前缀 | 实体 | 分配位置 | 文件名一致性 |
|---|---|---|---|
| M | 材料 | 材料登记表 | 文件名保持原名，M 号只在表里 |
| E | 证据 | 证据索引 | 文件名保持原名，E 号只在表里 |
| F | 待证事实（可选） | `案件信息.md` 的 F 清单 | 同上 |
| A | 研判 | 研判索引 | `A001-主题.md` 与索引行一致 |
| L | 线索 | 线索台账 | 有单文件时 `L001-简称.md` |
| V | 印证 | 印证台账 | 有单文件时 `V001-对象-核实.md` |
| T | 任务 | 任务台账 | 有单文件时 `T001-任务简称.md` |
| C | 会议 | 会议文件名 | `C001-日期-主题.md` |
| P | 人员 | 人员台账 | 目录 / 对象页 `P001-姓名` |
| O | 组织 | 组织架构 | 不建目录 |
| D | 文书 | 文书登记表 | `D001-文书-对象编号-日期.md` |

`P` / `O` 只给需要跨文档引用的对象编号；证人、被害人、办案民警写姓名，不编号。

## 编号分配

- 分配 = 同前缀当前最大值 + 1（`A001` → `A002`）。
- 写入前**重读**台账再取一次；冲突则重取（FR-042）。
- 已分配号不回收、不复用；作废允许留空。
- 编号与文件名、索引行三者一致；校验器检查重复与不一致。
- 不按页面或对话记忆手填编号；编号只由台账内容推导。

## 文件命名

我方新建文件的正则（FR-081、设计 §11.2）：

| 类型 | 正则 |
|---|---|
| 每日动态 | `^\d{4}-\d{2}-\d{2}-每日动态\.md$` |
| 沟通记录 | `^\d{4}-\d{2}-\d{2}-沟通记录-.+\.md$` |
| 会议 | `^C\d{3}-\d{4}-\d{2}-\d{2}-.+\.md$` |
| 任务 | `^T\d{3}-.+\.md$` |
| 线索 | `^L\d{3}-.+\.md$` |
| 研判 | `^A\d{3}-.+\.md$` |
| 印证 | `^V\d{3}-.+\.md$` |
| 人员对象页 | `^P\d{3}-.+\.md$` |
| 文书 | `^D\d{3}-.+-P\d{3}-\d{4}-\d{2}-\d{2}\.md$` |
| 笔录 | `^\d{4}-\d{2}-\d{2}-P\d{3}-笔录-\d{2}\.md$` |
| 案后处理清单 | `^P\d{3}-案后处理清单\.md$` |
| 发放版 | `^\d{4}-\d{2}-\d{2}-.+-发放版\.md$` |

目录名规则（不写进表格，避免正则里的竖线切断单元格）：

```text
二级目录：^\d{2}-[^\s\\/:*?"<>|]+$
三级人员目录：^[PO]\d{3}-.+$
```

日期统一 `YYYY-MM-DD`；同日多份用 `-01`、`-02`；版本写文件内「修订记录」，不进文件名。

## 硬规则与禁用词

- 只用半角 `-` 分隔；不用空格、括号、`#`、`?`、`*`。
- 禁用词（不得出现在我方新建文件名中）：`最终版` / `最新` / `修改版` / `副本` / `新建` / `未命名`。
- 目录名不用日期、不用「最终/最新/修改」等词。
- 版本写在文件内修订记录；发放版是只读快照，会后变更写 `变更日志.md`。
- 台账优先、文件按需：能用一行台账说清的，不单独建文件。
- 不确定名或类别时落 `99-其他`，标「待归类」，不猜。

## 目录创建白名单

- 顶层 7 个目录固定，AI 永不新建。
- 二级目录以初始化清单为白名单，AI 不得新建；新类别需求落 `99-其他`，出「目录变更建议」，人批准后创建并记 `变更日志.md`。
- 三级目录只允许两类：`P\d{3}-姓名/`（该人第一次出现时）与 `图表/`（第一次要归档图时）。
- 建目录必须有内容落位（初始化骨架除外）；不建空目录。
- `法律适用/` 不预建任何分类子目录。

## 文件头 frontmatter

我方新建的台账与文档统一文件头：

```yaml
---
id: L012
type: 线索
status: 待核查
source: E018
created_by: ai
updated: 2026-11-27
---
```

- `created_by` 只取 `ai` / `human`；`updated` 为 `YYYY-MM-DD`。
- `id`、`type`、`status` 与台账行一致；`source` 写来源编号或来源记录。
- 外部来件不强制加 frontmatter，也不改其原有内容。

## 外部来件豁免

- `材料/` 下的原件、`专案协同/00-原始记录/` 中的转写稿与外部文档**保留原文件名**，不受本节命名规则约束（FR-082）。
- AI 不擅自改名、不拆批、不复制；确需清理时先问人。
- 命名与禁用词校验跳过外部来件；材料条目检查排除材料登记表自身与 `.gitkeep`。
